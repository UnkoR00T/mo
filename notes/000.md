# 000_manifest.md

### Rola
AndroidManifest.xml + res/values/strings.xml aplikacji **mObywatel** (pakiet `pl.nask.mobywatel`, aplikacja `pl.gov.mc.fringers.mobywatel.MObywatelApplication`, label `mObywatel`, versionCode 56568, versionName 4.91.0 (6578), minSdk 26, targetSdk 36). Manifest daje: listę komponentów (Activity/Service/Provider), wymagane uprawnienia, deep linki, integracje zewnętrzne. strings.xml daje mapę wszystkich ekranów i komunikatów UI (teksty PL) - to najlepsze źródło nazewnictwa funkcji.

### Endpointy
- Deep link (nie API, ale kontrakt zewnętrzny):
  - `mobywatel://app/institutions...` -> MainActivity (plik: `AndroidManifest.xml`)
  - `https://api.mobywatel.gov.pl/application/diia_confirmed` (autoVerify) -> MainActivity, host potwierdza z backendu (plik: `AndroidManifest.xml`)
  - `mobywatel://eqsig` -> MainActivity, obsługa podpisu kwalifikowanego (plik: `AndroidManifest.xml`)
  - `mobywatel://app/service/pesel_restriction` -> MainActivity, ograniczenie PESEL (plik: `AndroidManifest.xml`)
- Innych endpointów brak (manifest nie zawiera base URL; `usesCleartextTraffic="false"`, `networkSecurityConfig=@xml/network_security_config` => tylko HTTPS).
- Uprawnienia sieciowe: `INTERNET`, `ACCESS_NETWORK_STATE` (plik: `AndroidManifest.xml`)
- Integracje: Google Maps (`com.google.android.geo.API_KEY`, `com.google.android.apps.maps`), ML Kit barcode (`com.google.android.gms.vision.DEPENDENCIES=barcode`), Google Places autocomplete, Google Wallet (`com.google.android.gms.wallet.api.enabled`), Firebase Messaging (FCM, kanał `general_channel_id`), Sentry (auto-init wyłączony), NFC, biometria, lokalizacja.

### Modele danych
Brak (manifest/strings nie definiują modeli).

### Logika
- `MainActivity` jest `launchMode="singleTask"`, `taskAffinity=""`, `windowSoftInputMode="adjustResize"`; obsługuje wszystkie deep linki powyżej (plik: `AndroidManifest.xml`).
- Sesja wygasa automatycznie: `InactivityLogoutService` (własny + `pl.gov.coi.common.lifecycle.inactivity.InactivityLogoutService` + `MJuniorInactivityLogoutService`) jako `JobService` (BIND_JOB_SERVICE) (plik: `AndroidManifest.xml`).
- `MObywatelApplication` jest `android:name` aplikacji - punkt wejścia DI (plik: `AndroidManifest.xml`).
- `FileProvider` authority `pl.nask.mobywatel.provider` - udostępnianie plików (np. PDF legitymacji) (plik: `AndroidManifest.xml`).
- `allowBackup="false"`, `largeHeap="true"`, `supportsRtl="false"` (plik: `AndroidManifest.xml`).

### UI / metryki
Dashboard = "pulpit" aplikacji (zamiast „dashboard" używamy w całej specyfikacji nazwy **Pulpit mObywatela**, czyli ekran główny z listą dokumentów). Z strings.xml wynikają nazwy ekranów/funkcji (wszystkie z `AndroidManifest.xml` jako źródłem tekstu, realne klasy w paczkach `*_ui.md`):
- Dodawanie dokumentów: `add_document_list_title` ("Wybierz dokumenty"), `add_document_main_document_screen_header_title` ("Dodaj pierwszy dokument"), ekrany potwierdzania tożsamości: `add_document_confirmation_method_*` (e-dowód / urząd gminy / profil zaufany lub bank), `add_document_office_code_*` (kod QR ważny X min %02d sek.), `add_document_generate_certificate_loading_title` ("Generujemy Twój nowy dokument"), `add_document_generate_certificate_remaining_time_*` (odliczany czas).
- Lista typów dokumentów (z `add_document_list_*`): mDowód (dowód osobisty z warstwą elektroniczną), mPrawo jazdy (+ tymczasowe), Legitymacja Szkolna, Legitymacja Studencka, Karta Dużej Rodziny, Małopolska Karta Aglomeracyjna, Legitymacja Ulgowych Usług Transportowych, Legitymacja emeryta-rencisty, Legitymacja adwokacka, Legitymacja poselska, Unijny Certyfikat COVID, Dokument ochrony czasowej (Diia), Moje pojazdy.
- Nawigacja/deep linki: `mobywatel://app/institutions` = ekran instytucji (prawdopodobnie mapa/ lista urzędów).
- Komunikaty: `add_document_async_main_result_success_button_secondary` = "Przejdź do pulpitu" (link powrotny do dashboardu), `add_document_async_result_button_to_documents` = "Przejdź do dokumentów".
- Zasady mDowód: ważny 5 lat; certyfikat i profil mObywatel ważne rok (`add_document_main_document_screen_identity_card_regulations_*`).
- Pomoc: `add_document_generate_certificate_help_contact` = `mobywatel-pomoc@coi.gov.pl`.
- Wersjonowanie: `versionName` w formacie `A.B.C (NNNN)` - NNNN to numer wewnętrzny buildu.

### Brakujące klasy
- `pl.gov.mc.fringers.mobywatel.MainActivity` - activity launcher + obsługa deep linków (prawdopodobnie w paczkach `*_ui.md`).
- `pl.gov.mc.fringers.mobywatel.MObywatelApplication` - klasa Application / DI container.
- `pl.gov.mc.fringers.mobywatel.manager.job.InactivityLogoutService` - serwis wylogowania po bezczynności.
- `pl.gov.coi.common.lifecycle.inactivity.InactivityLogoutService` - wspólny serwis wylogowania.
- `pl.gov.coi.mjunior.feature.inactivitylogout.MJuniorInactivityLogoutService` - wariant mJunior.
- `pl.gov.mc.fringers.mobywatel.pushNotification.FirebaseService` - odbiór FCM (paczka 647_ui.md zawiera `FirebaseService.java`).
- `com.google.android.gms.oss.licenses.*` - ekran licencji OSS (biblioteka).
- `com.google.android.libraries.places.widget.*` - Google Places autocomplete (biblioteka).
- `androidx.camera.core.impl.MetadataHolderService` - biblioteka CameraX.
