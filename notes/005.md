# 005_net.md

### Rola
`fv/z.java` (część 3/4) zawiera zaciemnioną klasę **`fv.z.a` = `okhttp3.OkHttpClient.Builder`** - builder klienta HTTP mObywatela (setery timeoutów, interceptorów, TLS, cert pinning, DNS, proxy, cookie jar) oraz konstruktor kopiujący z gotowego klienta. Brak logiki biznesowej aplikacji; wartości są domyślnymi ustawieniami OkHttp (brak evidence, że aplikacja je nadpisała - to builder, nie klient zainicjowany przez aplikację).

### Endpointy
brak

### Modele danych
- `fv.z.a` -> `okhttp3.OkHttpClient.Builder` (biblioteka): `pingInterval: int`, `minWebSocketMessageToCompress: long`, `routeDatabase: kv.h`, `dispatcher: fv.p`, `connectionPool: fr.k`, `interceptors: List<fv.w>`, `networkInterceptors: List<fv.w>`, `eventListenerFactory: fr.r.c`, `retryOnConnectionFailure: boolean`, `authenticator: fv.b`, `followRedirects: boolean`, `followSslRedirects: boolean`, `cookieJar: fv.n`, `dns: fv.q`, `proxy: Proxy`, `proxySelector: ProxySelector`, `proxyAuthenticator: fv.b`, `socketFactory: SocketFactory`, `sslSocketFactoryOrNull: SSLSocketFactory`, `x509TrustManagerOrNull: X509TrustManager`, `connectionSpecs: List<fv.l>`, `protocols: List<? extends fv.a0>`, `hostnameVerifier: HostnameVerifier`, `certificatePinner: fv.g`, `certificateChainCleaner: sv.c`, `callTimeout/connectTimeout/readTimeout/writeTimeout: int` (plik: `fv/z.java`)

### Logika
- Wartości domyślne buildera: `connectTimeout=readTimeout=writeTimeout=10000 ms`, `callTimeout=0` (bez limitu), `minWebSocketMessageToCompress=1024`, `retryOnConnectionFailure=true`, `followRedirects=followSslRedirects=true`, `certificatePinner=g.f67350d` (pusty - **brak pinowania świadectw w domyślnej konfiguracji**), `hostnameVerifier=sv.d.f184435a` (standardowy, NIE `ALLOW_ALL`), `cookieJar=n.f67472b`, `dns=q.f67483b` (systemowy DNS), `authenticator=b.f67263b` (brak), cache `n()` = `null` (brak cache HTTP) (plik: `fv/z.java`)
- `T(sslSocketFactory, trustManager)`: przy zmianie fabryki TLS / trust managera / pinnera / connectionSpecs / DNS zeruje `routeDatabase` (baza tras niekompatybilna) (plik: `fv/z.java`)
- `b()` -> `new z(this)` czyli zbudowanie klienta (plik: `fv/z.java`)
- Settery czasu: `c/Duration` = callTimeout, `f/Duration` = connectTimeout, `R/Duration` = readTimeout, `U/Duration` = writeTimeout; walidacja przez `gv.d.k(...)` (biblioteka, wymaga >0 i <= Integer.MAX_VALUE ms) (plik: `fv/z.java`)
- `a(w)` dodaje interceptor aplikacji (tu zapisywane są interceptory mObywatela/Sentry - same obiekty są w innych paczkach) (plik: `fv/z.java`)
