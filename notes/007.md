# 007_net.md

### Rola
`ge4/w.java` (część 1/2) to zaciemnione **`retrofit2.ServiceMethod`** (+ builder wewnętrzny `w.a`) biblioteki **Retrofit 2**. Parsuje adnotacje na metodzie interfejsu API (`@GET`, `@POST`, `@Path`, `@Query`, `@Header`, `@Field`, `@Part`, `@Body` itd. - po zaciemnieniu w paczce `ie4`) i buduje wewnętrzną specyfikację żądania (lista parserów parametrów `ge4.s.*`). Zero logiki aplikacji, zero endpointów - same reguły walidacji.

### Endpointy
brak (brak definicji interfejsów API aplikacji; wyłącznie mechanika wiązania adnotacji Retrofit)

### Logika
- `d(method, path, hasBody)`: zapisuje metodę HTTP + szablon URL; **odrzuca query z blokami `{...}`** (błąd: "URL query string must not have replace block. For dynamic query parameters use @Query") - potwierdzenie, że aplikacja nie używa replace-block w query (plik: `ge4/w.java`)
- `h(url)`: wyciąga nazwy placeholderów `\{([a-zA-Z][a-zA-Z0-9_-]*)\}` regexem i zapisuje jako `Set<String>` do walidacji `@Path` (plik: `ge4/w.java`)
- Walidacje krzyżowe (wszystkie w `ge4/w.java`): tylko jedna metoda HTTP; `@Path` tylko przy względnym URL i przed `@Query`; `@Url` niedopuszczalny razem z adnotacją URL i po `@Query`; `@Field`/`@FieldMap` tylko przy `@FormUrlEncoded`; `@Part`/`@PartMap` tylko przy `@Multipart`; `@Body` tylko przy metodzie z ciałem i nie w form/multipart; `@Tag` nie może się powtarzać; metoda form-encoded wymaga ≥1 `@Field`, multipart wymaga ≥1 `@Part`.
- `f(...)`: dla ostatniego parametru, jeśli typ to `tq.e` (RxJava `Single`/typ asynchroniczny lub `retrofit2.Response` zależnie od warstwy), zwraca `null` (parametr traktowany jako typ zwracany) i ustawia flagę synchroniczności (plik: `ge4/w.java`)
- `c(headers, allowUnsafeNonAscii)`: parsuje `@Headers` w formacie `"Name: Value"`, wyciąga `Content-Type` do osobnego pola `fv.x.e(...)`, resztę przez `fv.u.a.e(...)` (bezpieczne) lub `.a(...)` (gdy dopuszczono unsafe non-ASCII) (plik: `ge4/w.java`)
