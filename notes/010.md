# 010_net.md

### Rola
`i/AndroidCameraDevice.java` (część 1/9) to biblioteczna klasa **CameraX `androidx.camera.camera2.internal.AndroidCameraDevice`** - adapter `CameraDevice` (Camera2 API 2) na interfejs CameraX `i.m2`. Obsługuje tworzenie `CaptureRequest`, sesji przechwytywania i raportowanie błędów kamery do `cameraErrorListener`. Zero logiki aplikacji.

### Endpointy
brak

- `i.b4` -> `androidx.camera.camera2.internal.SessionStateCallback` (biblioteka), `i.i` -> `CameraDeviceStateCallback`/`StateCallback` (biblioteka), `i.l3` -> `OutputConfig` (interfejs CameraX), `i.t` -> helper `createCaptureSession` (biblioteka), `m.d` -> `CameraErrorListener` (interfejs CameraX), `h.q` -> `Camera2CameraInfo`/`CameraAccessException`-mapper błędów (biblioteka), `h.w.b` -> `CameraSessionState`/`SessionConfig`, `k.z` -> `CameraState` (CameraX), `h.x` -> `CameraInternal`, `fr.k` -> `ConnectionPool` (OkHttp, przypadkowo w konstruktorze syntetycznym) (plik: `i/AndroidCameraDevice.java`)

### Logika
- Pomiar czasu każdej operacji aparatu przez `k.h.f107050a.g().a()` (zegar monotoniczny CameraX `SystemClock`), raportowany w ms z 3 miejscami po przecinku oraz znacznikiem `Trace.beginSection("CXCP#...")` (plik: `i/AndroidCameraDevice.java`)
- Klasyfikacja wyjątków: `CameraAccessException` -> `cameraErrorListener.a(cameraId, h.q.INSTANCE.b(e), true)`; `IllegalArgumentException`/`SecurityException`/`UnsupportedOperationException`/`NullPointerException` -> `...m(), false`; `IllegalStateException` -> tylko log; inne -> rethrow. Błędy dokładnie te trafiają do Sentry przez `io.sentry.android.core.c2.g("CXCP", ...)` (plik: `i/AndroidCameraDevice.java`)
- `j(stateCallback)`: jeśli urządzenie nie jest zamknięte - nowy callback + `Boolean.TRUE`; inaczej natychmiastowe `onSessionFinalized` i `Boolean.FALSE` (plik: `i/AndroidCameraDevice.java`)
- Nieudane utworzenie sesji (`i0Var == null`) => finalizacja poprzedniej sesji (`onSessionFinalized`) i log do Sentry "Failed to create capture session... Finalizing previous session" (plik: `i/AndroidCameraDevice.java`)
- `M(...)` (createCaptureSession): mapuje `OutputConfiguration` interfejsu CameraX (`l3.c0(fr.q0.c(OutputConfiguration.class))`) na listę `android.hardware.camera2.params.OutputConfiguration` i woła `t.a(...)` z callbackiem `i` na wątku `this.threads.i()` (plik: `i/AndroidCameraDevice.java`)
