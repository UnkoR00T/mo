# 011_net.md

### Rola
`i/AndroidCameraDevice.java` (część 2/9) - biblioteczna klasa **CameraX `androidx.camera.camera2.internal.AndroidCameraDevice`**. Kontynuacja opisana w 010_net.md: zawiera wyłącznie metodę `N(...)` = `createReprocessableCaptureSession(InputConfiguration, List<Surface>, SessionStateCallback)` (sesja do reprocessingu obrazu, np. dla skanowania/NFC-ish pipeline), z obsługą wyjątków i pomiarem czasu. Zero logiki aplikacji mObywatela.

### Endpointy
brak

### Modele danych
- `i.AndroidCameraDevice.N` -> `AndroidCameraDevice.createReprocessableCaptureSession` (metoda biblioteki CameraX, nie klasa) (plik: `i/AndroidCameraDevice.java`)
- `i.b4` -> `CameraXSessionStateCallback` (biblioteka), `k2.a` -> `CameraXSessionStateCallbackInternal` (interfejs biblioteki), `m.d` -> `CameraXCameraErrorListener`, `h.q` -> `Camera2CameraInfo` + maper `CameraAccessException` -> `CameraState.Type` (biblioteka) (plik: `i/AndroidCameraDevice.java`)
- `io.sentry.android.core.c2` -> `SentryLogger` (biblioteka), `k.k` -> `MobCameraCustomLogger`, `k.h` -> `CameraXSystemClock`, `k.i` -> `CameraXTraceClock`, `k.c0` -> `MobLoggerFormatter` (plik: `i/AndroidCameraDevice.java`)

### Logika
- `N(...)`: najpierw `j(stateCallback)` - jeśli urządzenie jest zamknięte, zwraca `false` bez próby utworzenia sesji; w przeciwnym razie finalizuje poprzednią sesję (`k(b4VarB)`) (plik: `i/AndroidCameraDevice.java`)
- Ścieżka sukcesu: `cameraDevice.createReprocessableCaptureSession(input, outputs, <SessionStateCallback>, threads.i())` - callback budowany przez wewnętrzną klasę sesji `i` (plik: `i/AndroidCameraDevice.java`)
- Klasyfikacja wyjątków (ta sama co w 010_net.md): `CameraAccessException` -> `cameraErrorListener.a(cameraId, h.q.INSTANCE.b(e), true)` + log Sentry `"Camera encountered an error"`; `IllegalArgumentException`/`SecurityException`/`UnsupportedOperationException`/`NullPointerException` -> `cameraErrorListener.a(cameraId, h.q.INSTANCE.m(), false)` + log Sentry `"Unexpected exception"`; `IllegalStateException` -> wyłącznie log (nie przerywa); inne -> rethrow (plik: `i/AndroidCameraDevice.java`)
- Niepowodzenie utworzenia sesji -> log Sentry `"Failed to create reprocess session from <cameraDevice>. Finalizing previous session"` + `l(b4Var)` (finalizacja sesji); metoda zwraca wynik sukcesu (plik: `i/AndroidCameraDevice.java`)
- Pomiar czasu: `Trace.beginSection("CXCP#createReprocessableCaptureSession-" + getCameraId())` / `Trace.endSection()`, czas liczony przez `k.h...g().a()` (monotoniczny, w nanosekundach) i konwertowany na milisekundy przez `k.i.c(ns)` oraz dzielony przez `1_000_000.0` do formatu `"%.3f ms"` (plik: `i/AndroidCameraDevice.java`)

### UI / metryki
brak. Jedyna metryka to wewnętrzny czas trwania operacji aparatu logowany jako `"%.3f ms"` (bez wysyłania do UI/Sentry poza komunikatami błędów oznaczonymi tagiem `"CXCP"`).
