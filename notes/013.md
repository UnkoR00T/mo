# 013_net.md

### Rola
`i/AndroidCameraDevice.java` (część 4/9) - biblioteczna klasa **CameraX `androidx.camera.camera2.internal.AndroidCameraDevice`**. Zawiera wyłącznie `T0(List<Surface>, SessionStateCallback)` = `createCaptureSession` (standardowa sesja przechwytywania, wariant `createCaptureSession(List<Surface>)`). Zero logiki aplikacji mObywatela.

### Endpointy
brak

### Modele danych
- `i.AndroidCameraDevice.T0` -> `AndroidCameraDevice.createCaptureSession(List<Surface>)` (metoda biblioteki CameraX, nie klasa) (plik: `i/AndroidCameraDevice.java`)
- `i.i` -> `CameraXDeviceStateCallback` (wewnętrzna klasa sesji przekazywana do `cameraDevice.createCaptureSession`; implementuje `SessionStateCallback`) (plik: `i/AndroidCameraDevice.java`)
- `i.b4` -> `CameraXSessionStateCallback`, `k2.a` -> `CameraXSessionStateCallbackInternal`, `m.d` -> `CameraXCameraErrorListener`, `h.q` -> `Camera2CameraInfo` + maper wyjątków, `k.h` -> `CameraXSystemClock`, `k.i` -> `CameraXTraceClock`, `k.k` -> `MobCameraCustomLogger`, `k.c0` -> `MobLoggerFormatter`, `io.sentry.android.core.c2` -> `SentryLogger` (biblioteki) (plik: `i/AndroidCameraDevice.java`)

### Logika
- `j(stateCallback)`: przy zamkniętym urządzeniu zwraca `false` (bez tworzenia sesji); w przeciwnym razie finalizuje poprzednią sesję przez `k(b4VarB)` (plik: `i/AndroidCameraDevice.java`)
- Ścieżka sukcesu: `cameraDevice.createCaptureSession(outputs, new i(...), threads.i())` - wywołanie asynchroniczne na wątku `threads.i()` (plik: `i/AndroidCameraDevice.java`)
- Klasyfikacja wyjątków (ta sama co 010/011/012_net.md): `CameraAccessException` -> `cameraErrorListener.a(cameraId, h.q.INSTANCE.b(e), true)` + log Sentry `"Camera encountered an error"`; `IllegalArgumentException`/`SecurityException`/`UnsupportedOperationException`/`NullPointerException` -> `h.q.INSTANCE.m(), false` + `"Unexpected exception"`; `IllegalStateException` -> tylko log; inne -> rethrow (plik: `i/AndroidCameraDevice.java`)
- Niepowodzenie utworzenia sesji -> log Sentry `"Failed to create capture session from " + cameraDevice + ". Finalizing previous session"` + `l(b4Var)` (finalizacja poprzedniej sesji) (plik: `i/AndroidCameraDevice.java`)
- Pomiar czasu: `Trace.beginSection("CXCP#createCaptureSession-" + getCameraId())` / `Trace.endSection()`, czas monotoniczny w ns konwertowany przez `k.i.c(...)` i dzielony przez `1_000_000.0` do `"%.3f ms"` (plik: `i/AndroidCameraDevice.java`)

### UI / metryki
brak. Metryka wewnętrzna: czas trwania `createCaptureSession` w ms (3 miejsca po przecinku, log); błędy do Sentry z tagiem `"CXCP"`.
