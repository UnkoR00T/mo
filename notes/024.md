- `i.k2` – `Camera2SessionConfig`/sesja: metody `stopRepeating()`, `getInputSurface()`, `getDevice()`, `e2/L2` (submit single), `B1/r0` (submit burst/list). Plik `i/o1.java`.

### Logika
- `V(captureSequence)`: pod blokadą; po rozłączeniu log i `null`. Wybór API sesji: jeśli liczba żądań ≠ 1 lub sesja high-speed (`l2`) → `B1(...)`/`r0(...)` (submit listy) zależnie od `getRepeating()`; dla pojedynczego powtarzanego → zapamiętanie w `lastSingleRepeatingRequestSequence` (gdy `awaitRepeatingRequestOnDisconnect`) i `e2(...)`; pojedynczego niepowtarzanego → `L2(...)`. Zwraca `Integer` (id sekwencji). Plik `i/o1.java`.
- `n()` (disconnect): blokada, ustawienie `disconnected = true`, zamknięcie `imageWriter` przez `CON.j0.a(...)`, zwolnienie `inputSurface.release()`; po blokadzie, jeśli `awaitRepeatingRequestOnDisconnect`, wywołanie `j(lastSingleRepeatingRequestSequence)` (await, patrz 022 – timeout 2000 ms). Całość w `Trace.beginSection(this + "#disconnect")`. Plik `i/o1.java`.
- `stopRepeating()`: delegacja pod blokadą. `toString()` = `"Camera2CaptureSequenceProcessor-" + debugId`. Plik `i/o1.java`.
- Konstruktor: tworzy `ImageWriter` tylko gdy `streamGraph.b()` niepuste; brak `inputSurface` → `IllegalStateException("inputSurface is required to create instance of imageWriter.")`; `RuntimeException` przy tworzeniu → log „Failed to create ImageWriter ... Reprocessing will not be supported!" i `imageWriter = null`. Plik `i/o1.java`.
