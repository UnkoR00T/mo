### Logika
- `Companion.a(response, request)`: biała lista kodów HTTP uznawanych za cacheable: `200, 410, 414, 501, 203, 204` (oraz `307, 308, 404, 405`); `300/301` bezwarunkowo; `302` tylko gdy nagłówek `Expires` istnieje; `307` tylko gdy `Expires` istnieje LUB `max-age != -1` LUB `isPublic` LUB `isPrivate`. Wszystkie inne kody -> `false`. Na końcu `false` jeśli `response.cacheControl.noStore || request.cacheControl.noStore`. Plik `iv/b.java`.
- Konstruktor `C2275b`: parsuje nagłówki odpowiedzi (porównanie case-insensitive przez `r.G`): `Date` -> `servedDate` + `servedDateString`, `Expires` -> `expires`, `Last-Modified` -> `lastModified` + `lastModifiedString`, `ETag` -> `etag`, `Age` -> `ageSeconds` (domyślnie `-1` gdy brak); zapamiętuje `sentRequestMillis` i `receivedResponseMillis` z odpowiedzi. Plik `iv/b.java`.
- `a()` (wiek odpowiedzi): `max(0, receivedResponseMillis - servedDate)`; jeśli nagłówek `Age` obecny -> `max(wieciek, ageSeconds * 1000)`; do tego dolicza `receivedResponseMillis - sentRequestMillis` + `nowMillis - receivedResponseMillis` (łączny czas od wysłania do teraz). Plik `iv/b.java`.
- `d()` (freshness lifetime, kolejność): 1) `cacheResponse.max-age * 1000`; 2) `expires - (servedDate ?: receivedResponseMillis)` gdy dodatnie, inaczej `0`; 3) heurystyka: jeśli `lastModified != null` i URL żądania cache nie ma query (`getUrl().o() == null`) -> `(servedDate ?: sentRequestMillis) - lastModified`, dzielone przez **10** (10% reguły RFC); 4) `0`. Plik `iv/b.java`.
- `c()` (decyzja):
  - brak `cacheResponse` -> `CacheStrategy(request, null)`;
  - warunek cacheable: `(!request.g() || cacheResponse.getHandshake() != null)` && `isCacheable(cacheResponse, request)`; jeśli nie spełniony -> `CacheStrategy(request, null)`;
  - `request.cacheControl.noCache` LUB `hasConditionalHeaders(request)` -> `CacheStrategy(request, null)` (wymuszone odświeżenie);
  - `maxStaleMillis` = `maxStale * 1000` tylko gdy `!cacheResponse.cacheControl.mustRevalidate`;
  - `minFreshMillis` = `minFresh * 1000` lub `0`;
  - `freshnessLifetimeMillis` przycięte przez `min(request.max-age * 1000, ...)` gdy `max-age` w żądaniu != `-1`;
  - jeśli `!cacheResponse.cacheControl.noCache` i `(minFresh + age) < (maxStale + freshnessLifetime)` -> zwrot z cache: budowa odpowiedzi z `cacheResponse.K()` i nagłówków `Warning`: `"110 HttpURLConnection \"Response is stale\""` gdy `minFresh + age >= freshnessLifetime`, oraz `"113 HttpURLConnection \"Heuristic expiration\""` gdy `age > 86400000` (24 h) i `f()` (brak jawnego `max-age`/`Expires`);
  - w przeciwnym razie żądanie warunkowe: `If-None-Match` = `etag`, jeśli brak to `If-Modified-Since` = `lastModifiedString`, a gdy brak i `servedDate == null` -> zwykłe żądanie sieciowe; nagłówek dodawany przez `request.getHeaders().g().d(...)`, a żądanie odtwarzane przez `request.i().e(headers).b()` (przepisane nagłówki). Plik `iv/b.java`.
- `b()`: po `c()` – jeśli `networkRequest == null` i `request.cacheControl.onlyIfCached` -> `CacheStrategy(null, null)` (oznaczenie „tylko z cache, brak trafienia”). Plik `iv/b.java`.
