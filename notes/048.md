# 048_net.md

### Rola
Druga część wygenerowanego komponentu Daggera (`m14/c.java`, `common_release`). Ten fragment zawiera kompletną konfigurację warstwy sieciowej: budowanie klienta HTTP, konfigurację TLS (mTLS, polityka Certificate Transparency), weryfikację podpisów odpowiedzi, pobieranie OCSP/CRL oraz interceptory (w tym auth). Nazwy parametrów Daggera (zachowane w metadanych) odsłaniają role bez zaglądania w implementacje.

### Endpointy
brak URL i metod HTTP. Warstwa sieciowa jest wstrzykiwana abstrakcyjnie przez `ay.a baseUrlProvider` (dostawca adresu bazowego) i `pl.gov.coi.common.network.HttpRequestExecutor`. Interfejs API aplikacji nie jest w tym pliku.
