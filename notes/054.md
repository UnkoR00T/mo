# 054_net.md

### Rola
`nv/f.java` (część 4/5) to **`okhttp3.internal.http2.Http2Connection`** (realna nazwa widoczna w metadanych: `nv/f` z `d2 = {"nv/f", ...}` oraz klasa bazowa `jv.a` = `okhttp3.internal.NamedRunnable`). Zawiera konstruktor, zarządzanie strumieniami HTTP/2 (tworzenie, reset, okno przepływu, SETTINGS, keepalive PING/PONG) oraz wyłączenie połączenia. Zero logiki aplikacji.

### Endpointy
brak (brak URL-i, nagłówków HTTP ani warstwy aplikacji — surowy stan protokołu HTTP/2 na `Socket`)

### Modele danych
- `nv.f` -> `Http2Connection` (biblioteka). Pola widoczne w tej paczce: `client: boolean` (czy strona klienta), `listener` (PushStreamListener), `streams: LinkedHashMap<Integer, nv.i>` (aktywne strumienie), `connectionName: String` (nazwa do logów/kolejek), `nextStreamId: int` (najbliższy identyfikator strumienia: 3 dla klienta, 2 dla serwera — nieparzyste dla klienta), `taskRunner: jv.e`, `writerQueue`/`pushQueue`/`settingsListenerQueue` (trzy kolejki zadań), `pushObserver` (interfejs zdarzeń PUSH), `okHttpSettings`/`peerSettings: m` (SETTINGS), `writeBytesMaximum: long`, `writeBytesTotal: long`, `socket`, `writer: nv.j` (FrameWriter), `readerRunnable: d` (pętla czytająca), `currentPushRequests: LinkedHashSet<Integer>` (żądania PUSH w toku), `isShutdown: boolean`, `lastGoodStreamId: int`, `intervalPingsSent`/`intervalPongsReceived: long`, `degradedPingsSent`/`degradedPongsReceived: long`, `degradedPongDeadlineNs: long` (keepalive dla „degraded" połączeń) (plik: `nv/f.java`)
- `nv.i` -> `Http2Stream` (strumień HTTP/2) (plik: `nv/f.java`)
- `nv.j` -> `FrameWriter` (writer klatek HTTP/2); metody `I(streamId, errorCode)` = RST_STREAM, `K(streamId, bytes)` = WINDOW_UPDATE, `y/H` = HEADERS, `u(lastGoodStreamId, code, ...)` = GOAWAY, `flush()`, `close()` (plik: `nv/f.java`)
- `nv.b` -> `ErrorCode` (`PROTOCOL_ERROR`, `REFUSED_STREAM`, `CANCEL`) (plik: `nv/f.java`)
- `nv.m` -> `Settings` (SETTINGS HTTP/2); `m.h(id, value)`, `m.c()` (maks. bajtów okna); wartości `7 = INITIAL_WINDOW_SIZE (65535, 16384; 16777216 dla klienta)`, `5 = MAX_FRAME_SIZE` (plik: `nv/f.java`)
- `nv.c` -> `Headers` (nagłówki klatkowe HTTP/2) (plik: `nv/f.java`)
- `nv.a` -> `StreamResetException`/wyjątek „stream shut down" (rzucany przy `isShutdown`) (plik: `nv/f.java`)
- `nv.j` (jako klasa zagnieżdżona `l`), `jv.e` (TaskRunner), `jv.d` (Queue/TaskQueue), `fr.n0`, `fr.p0`, `gv.d` (Level/logger), `oq.i0` (Kompozytor/instrumentacja) — biblioteka

### Logika
- Konstruktor: `nextStreamId = client ? 3 : 2`; kolejki z `taskRunner.i()`; `writeBytesMaximum = peerSettings.c()`; jeśli `getPingIntervalMillis() != 0`, planuje `j ping` z opóźnieniem `TimeUnit.MILLISECONDS.toNanos(pingIntervalMillis)` (plik: `nv/f.java`)
- `i1(associatedStreamId, requestHeaders, out)` (nowy strumień): odrzuca `nextStreamId > 1073741823` przez `REFUSED_STREAM`; zwiększa `nextStreamId` o 2 (parzystość); dla klienta `associatedStreamId` musi być 0 („client streams shouldn't have associated stream IDs"); flush tylko gdy przekroczono `writeBytesMaximum` (plik: `nv/f.java`)
- `C1` (PUSH_REQUEST): rejestruje `streamId` w `currentPushRequests` i kolejkuje `onRequest` z opóźnieniem 0; duplikat → `PROTOCOL_ERROR` (plik: `nv/f.java`)
- `F1(streamId)`: poprawność identyfikatora — `!= 0 && parzysty` (plik: `nv/f.java`)
- `P1()`: keepalive połączeń „degraded" — jeśli `degradedPongsReceived >= degradedPingsSent`, to `degradedPingsSent++`, `degradedPongDeadlineNs = System.nanoTime() + 1_000_000_000` (1 s) i kolejkuje PING (plik: `nv/f.java`)
- `T1(statusCode)`: GOAWAY z `lastGoodStreamId`, zapisanym w obiekcie `fr.n0` (lista błędów / „recoverable errors") — powtarzalnie, tylko jeśli `!isShutdown` (plik: `nv/f.java`)
- `Z(connectionCode, streamCode, cause)`: pełne zamknięcie — GOAWAY, iteracja po `streams` z `iVar.d(streamCode, cause)`, zamknięcie writera i `socket`, opróżnienie trzech kolejek (`n()`); asercja, że `Thread.holdsLock(this)` jest fałszywe (plik: `nv/f.java`)
- `a0(IOException)` → `Z(PROTOCOL_ERROR, PROTOCOL_ERROR, cause)` (plik: `nv/f.java`)
- `K1(streamId)`: usuwa strumień i robi `notifyAll()` (blokada na `this` przy oczekiwaniu na wolne strumienie) (plik: `nv/f.java`)
- Retry/backoff w tym pliku: brak (jedyna stała to 1 s dla `degradedPongDeadlineNs` i interwał PING z konfiguracji klienta)
