# 057_net.md

### Rola
`nv/i.java` (część 2/2) to drugie pół `okhttp3.internal.http2.Http2Stream` — konstruktor strumienia, kolejka nagłówków odpowiedzi, blokada monitora (`wait`/`notifyAll`), propagacja kodów błędów (RST_STREAM) i finalizacja strumienia. Zero logiki aplikacji.

### Endpointy
brak (brak URL-i, nagłówków warstwy aplikacji i Retrofit — wewnętrzna maszyn stanów HTTP/2)

### Modele danych
- `nv.i` -> `Http2Stream`: pola `id: int`, `connection: nv.f`, `writeBytesMaximum: long`, `headersQueue: ArrayDeque<u>` (kolejka nagłówków), `readTimeout/writeTimeout: d`, `errorCode: nv.b`, `errorException: IOException`, `hasResponseHeaders: boolean` (plik: `nv/i.java`)
- `nv.i$d` -> `StreamTimeout` (extends `vv.c`): `B()` przy starcie odliczania czasu → `f(CANCEL)` + `connection.P1()`; `C()` rzuca `SocketTimeoutException("timeout")` jeśli `t()` (wygasł); `v(cause)` opakowuje przyczynę w `SocketTimeoutException` (plik: `nv/i.java`)
- `nv.b` -> `ErrorCode`, `nv.u` -> `Headers`, `nv.n` -> `StreamResetException` (plik: `nv/i.java`)
- `vv.c` -> `AsyncTimeout` (okio), `vv.l0` -> `Timeout` (plik: `nv/i.java`)

### Logika
- Konstruktor `i(id, connection, outFinished, inFinished, headers)`: `writeBytesMaximum = connection.peerSettings.c()` (okno z SETTINGS peera), `source = new c(connection.okHttpSettings.c(), inFinished)` (limit odczytu = własne okno), `sink = new b(outFinished)`; walidacja — zdalnie inicjowany strumień musi mieć nagłówki (`"remotely-initiated streams should have headers"`), lokalnie inicjowany nie może (`"locally-initiated streams shouldn't have headers yet"`) (plik: `nv/i.java`)
- `e(errorCode, errorException)` (ustawienie błędu, pod monitorem): ignoruje jeśli błąd już istnieje; zapisuje `errorCode`/`errorException`, `notifyAll()`; jeśli nie zamknięto obu kierunków (`source.finished && sink.finished`) → `connection.K1(id)` (powiadomienie końca strumienia) i zwraca `true` (plik: `nv/i.java`)
- `d(rstStatusCode, errorException)` → przy pierwszym błędzie `connection.A2(id, rstStatusCode)` (wysłanie RST_STREAM); `f(errorCode)` → `connection.I2(id, errorCode)` (plik: `nv/i.java`)
- `C()` (odczyt nagłówków odpowiedzi, `synchronized` + `readTimeout`): pętla `while headersQueue.isEmpty() && errorCode == null` → `D()` (czeka na `notifyAll`); po wybudzeniu: jeśli kolejka pusta → rzuca `errorException` lub `new n(errorCode)`; inaczej `headersQueue.removeFirst()` (plik: `nv/i.java`)
- `D()` → `wait()`, przy `InterruptedException` → `Thread.currentThread().interrupt()` + `InterruptedIOException` (plik: `nv/i.java`)
- `x(headers, inFinished)` (nagłówki odpowiedzi): jeśli `hasResponseHeaders && inFinished` → `headers` traktowane jako `trailers` (`source.r`), inaczej `hasResponseHeaders = true` i `headersQueue.add`; `inFinished` → `source.p(true)`; następnie `notifyAll()` i (jeśli `!u()`) `connection.K1(id)` (plik: `nv/i.java`)
- `a(delta)` (delta okna od WINDOW_UPDATE): `writeBytesMaximum += delta`, przy `delta > 0` → `notifyAll()` (budzi zablokowany zapis) (plik: `nv/i.java`)
- `b()` (zamknięcie): jeśli źródło zakończone i zamknięte oraz sink zakończony lub zamknięty → `d(CANCEL, null)`; w przeciwnym razie jeśli `!u()` → `connection.K1(id)` (plik: `nv/i.java`)
- `u()` (`isStreamDone`): `false` gdy `errorCode != null`; `false` gdy oba kierunki zakończone/zamknięte **oraz** `hasResponseHeaders`; w przeciwnym razie `true` (plik: `nv/i.java`)
- `t()` (`isLocallyInitiated`): `connection.client == ((id & 1) == 1)` — parzystość identyfikatora strumienia określa inicjatora (nieparzyste = klient) (plik: `nv/i.java`)
- `c()` (sprawdzenie przed zapisem): `IOException("stream closed")` / `IOException("stream finished")` / rzut `StreamResetException` przy ustawionym `errorCode` (plik: `nv/i.java`)
- `n()` (`getSink()`): `IllegalStateException("reply before requesting the sink")` gdy brak nagłówków odpowiedzi i strumień nie lokalny (ochrona przed żądaniem body przed HEADERS) (plik: `nv/i.java`)
- `y(errorCode)`: pod monitorem ustawia `errorCode` tylko jeśli wcześniej `null`, potem `notifyAll()` (plik: `nv/i.java`)
- `w(source, length)` → `source.m(source, length)` (przekazanie danych DATA do odczytu); `A/B/z` — settery `readBytesTotal`/`writeBytesTotal`/`readBytesAcknowledged` (plik: `nv/i.java`)
- Retry/backoff: brak. Interwały: brak (odliczanie czasu w `StreamTimeout` — wartości ustawiane poza paczką)
