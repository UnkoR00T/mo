# 058_net.md

### Rola
`o90/k.java` to **moduł DI (Hilt/Dagger — singleton, prywatny konstruktor + statyczna instancja `f143437a`)** dostarczający warstwę sieciową aplikacji: klient HTTP (OkHttp/Retrofit), łańcuch interceptorów (w tym **interceptor autoryzacji**), obsługę błędów sieciowych, factory bazy danych z kluczem sprzętowym oraz **menedżera sesji z tokenami opartym na aktywnym certyfikacie użytkownika** (mTLS). To najważniejsza paczka z dotychczas przeczytanych — opisuje kontrakt warstwy sieciowej, choć bez adresów URL.

### Logika
- Wstrzykiwanie jest statyczne (Hilt): każda metoda to `@Provides` o zakresie singleton; `k()` tworzy `g4` (DataStore), `r(g4)` tworzy `i4` (implementację DataStore) (plik: `o90/k.java`)
- Kolejność elementów `p00.g(...)` wskazuje kolejność w łańcuchu interceptorów: config → blokada cleartext → **auth** → połączenie sieciowe → nagłówki domyślne → logowanie zdalne → mock bazy URL (plik: `o90/k.java`)
- Warstwa sesji: `wy.b` (NetworkSessionManager) powstaje z `isUserCertActiveUC` + `checkActivationStateUC` + `sessionTokenLoader` + `currentTimeProvider`, a token dostępu z `qf0.a` (loadAccessTokenUC) — wskazuje, że autoryzacja jest powiązana ze stanem aktywacji i ważnością certyfikatu użytkownika (plik: `o90/k.java`)
- Krypto bazy: `p10.d` (klucz bazy) zależy od `wy.a` (klucz główny z zewnątrz); baza szyfrowana kluczem, nie wprost dostępnym (plik: `o90/k.java`)
- Podpisywanie zapytań: brak w tej paczce; obecne jedynie mechanizmy bezpieczeństwa TLS/mTLS i wyłączenia weryfikacji (`a0`, `c0`, `y00.x`) przekazywane jako opcjonalne nadpisania (plik: `o90/k.java`)
- Retry/backoff, interwały, agregacje: brak w kodzie (konfiguracja leży w `pl.gov.coi.common.network.r` i `p00.f`, poza paczką)
