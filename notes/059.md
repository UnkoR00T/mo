# 059_net.md

### Rola
`ol/c.java` (część 1/2) to klient **Firebase Installations Service (FIS)** — biblioteka `com.google.firebase:firebase-installations`. Tworzy/odświeża identyfikator instalacji (FID) i token autoryzacyjny wysyłany do `firebaseinstallations.googleapis.com` nad `HttpURLConnection`. Zero logiki aplikacji mObywatel.

### Endpointy
Wszystkie do hosta `firebaseinstallations.googleapis.com`, ścieżka `/v1/projects/<projectId>/installations` (z `String.format("https://%s/%s/%s", "firebaseinstallations.googleapis.com", "v1", ...)`) — plik: `ol/c.java`
- **POST** `/v1/projects/{str3}/installations` — rejestracja instalacji (metoda `d(firebaseAppId, str2, str3, str4, str5)`): body gzip z `{"fid","appId","authVersion":"FIS_v2","sdkVersion":"a:19.1.0"}` (plik: `ol/c.java`)
  - parametry wejściowe `d(str, str2, str3, str4, str5)`: `str` = API key Firebase, `str2` = fid (identyfikator instalacji), `str3` = project ID, `str4` = application ID, `str5` = token migracji IID (opcjonalny) (plik: `ol/c.java`)
  - nagłówki żądania (metoda `l(url, apiKey)`): `Content-Type: application/json`, `Accept: application/json`, `Content-Encoding: gzip`, `Cache-Control: no-cache`, `X-Android-Package: <packageName>`, `x-firebase-client: <heartbeats header>`, `X-Android-Cert: <base64(SHA-1) certyfikatu aplikacji>`, `x-goog-api-key: <apiKey>`, opcjonalnie `x-goog-fis-android-iid-migration-auth: <str5>` (plik: `ol/c.java`)
  - timeouts: connect 10000 ms, read 10000 ms, `setUseCaches(false)`; `TrafficStats.setThreadStatsTag(32769)` (metryka ruchu sieciowego Androida) (plik: `ol/c.java`)
- **POST** (tej samej ścieżki) z body `{"installation":{"sdkVersion":"a:19.1.0"}}` (metoda `r`) — odświeżenie istniejącej instalacji (plik: `ol/c.java`)
- Odpowiedź 2xx parsowana strumieniowo przez `android.util.JsonReader`: `name`, `fid`, `refreshToken`, `authToken.token`, `authToken.expiresIn` (metody `n`, `p`) (plik: `ol/c.java`)
- Podpisywanie: brak (wyłącznie nagłówek `x-goog-api-key` i skrót certyfikatu `X-Android-Cert`)

### Logika
- `m(expiration)` (metoda `static`): `Pattern.compile("[0-9]+s")` wymusza format czasu wygaśnięcia; obcina końcowe `s` i `Long.parseLong`; pusty/zerowy czas → `0L` (plik: `ol/c.java`)
- `b(fid, appId)`: buduje JSON `{fid, appId, authVersion="FIS_v2", sdkVersion="a:19.1.0"}`; `c()`: `{installation:{sdkVersion="a:19.1.0"}}` (plik: `ol/c.java`)
- `s(connection, bytes)`: zapis body przez `GZIPOutputStream` na `getOutputStream()` (gzip zgodny z nagłówkiem `Content-Encoding: gzip`) (plik: `ol/c.java`)
- `i(responseCode)`: sukces = `200 <= kod < 300` (plik: `ol/c.java`)
- `f()`: odcisk podpisu aplikacji z `PackageManager` kodowany base64 przez `h.a(bytes, false)`; brak pakietu / wyjątek → `null` i log (tag `"ContentValues"`) (plik: `ol/c.java`)
- `d(...)` (punk wejścia): brak dostępności (`!e.b()`) → wyjątek `UNAVAILABLE`; **pętla `for (int i15 = 0; i15 <= 1; i15++)`** = dokładnie 2 próby; po każdej: log statystyki `e.f(responseCode)`; 2xx → parsowanie odpowiedzi; `429` → `TOO_MANY_REQUESTS`; kod poza 2xx i poza `[500,600)` → `BAD_CONFIG` + ostrzeżenie o brakujących opcjach Firebase (API key, Project ID, Application ID); po wyczerpaniu prób → `UNAVAILABLE`; w `finally`/`catch` zawsze `disconnect()` + `TrafficStats.clearThreadStatsTag()` (plik: `ol/c.java`)
- `o(connection)` (odczyt `errorStream`): składa komunikat `Error when communicating with the Firebase Installations server API. HTTP response: [%d %s: %s]` (plik: `ol/c.java`)
- Retry/backoff: brak backoffu — 2 twarde próby bez opóźnień. Interwały: 10 s connect, 10 s read
