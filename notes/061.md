# 061_net.md

### Rola
`ov/h.java` to `okhttp3.internal.platform.Platform` — bazowa klasa abstrakcyjna okhttp3 odpowiedzialna za warstwę TLS/platformy: wybór dostawcy TLS, budowa `SSLContext`, `SSLSocketFactory`, `X509TrustManager`, lista protokołów ALPN oraz socket connect. Biblioteka, bez logiki aplikacji.

### Endpointy
brak (brak URL-i i wywołań HTTP; kryptografia/transport)

### Logika
- Wybór platformy w `Companion.f()`: `h() ? d() : e()` — na Dalvik/Android (`t.c("Dalvik", System.getProperty("java.vm.name"))`) używana jest ścieżka `d()`, poza nią `e()` (plik: `ov/h.java`)
- `e()` (kolejność preferencji dostawców TLS): `d` jeśli `j()` (Conscrypt jest pierwszym `Security.getProviders()`) → `c` jeśli `i()` (BouncyCastle pierwszy) → `g` jeśli `k()` (OpenJSSE pierwszy) → `f` (OkHttp) → `e` (Jdk) → `new h()` (bazowa) (plik: `ov/h.java`)
- `d()`: `pv.c.f162811a.b()` i `a.INSTANCE.a()`; jeśli brak providerów systemowych → `b.f150183f.a()` (AndroidPlatform) (plik: `ov/h.java`)
- `b(protocols)`: filtruje `a0.HTTP_1_0` z listy i mapuje do `getProtocol()` (lista ALPN do TLS) (plik: `ov/h.java`)
- `c(protocols)`: serializuje nazwy protokołów do `Buffer` w formacie ALPN: bajt długości + bajty nazwy (prefiksowanie długością) (plik: `ov/h.java`)
- `m()`: `SSLContext.getInstance("TLS")`; `n(trustManager)`: `init(null, [trustManager], null)` + `getSocketFactory()`, `GeneralSecurityException` → `AssertionError("No System TLS: ...")` (plik: `ov/h.java`)
- `o()`: `TrustManagerFactory.getInstance(defaultAlgorithm)`, `init((KeyStore) null)` (domyślny magazyn zaufanych CA systemu); wymaga dokładnie jednego trust managera będącego `X509TrustManager`, inaczej `IllegalStateException("Unexpected default trust managers: ...")` (plik: `ov/h.java`)
- `d(trustManager)` / `c(trustManager)`: `CertificateChainCleaner` z kopią `trustManager.getAcceptedIssuers()` (`Arrays.copyOf`) (plik: `ov/h.java`)
- `f(socket, address, connectTimeout)`: `socket.connect(address, connectTimeout)` (plik: `ov/h.java`)
- `i(hostname)`: zawsze `true` (weryfikacja hosta w klasie bazowej; nadpisywana przez podklasy) (plik: `ov/h.java`)
- `g(sslSocket)`: `null` (brak ALPN negotiated protocol w bazie); `e(sslSocket, hostname, protocols)`, `b(sslSocket)`: puste implementacje bazowe (plik: `ov/h.java`)
- `j(message, level, throwable)`: poziom `5` → `Level.WARNING`, inaczej `Level.INFO` (plik: `ov/h.java`)
- `l(message, stackTrace)`: komunikat podpowiadający włączenie loggera `OkHttpClient` na poziom `FINE`; `h(closer)` zwraca `Throwable` tylko gdy `isLoggable(FINE)` (alokacja stosu przy debugowaniu) (plik: `ov/h.java`)
- Interwały: brak; timeouty przekazywane parametrami (`connectTimeout`)
