# 063_net.md

### Rola
`p00/h.java` to **model profilu połączenia sieciowego** aplikacji — klasa bazowa (niepubliczny konstruktor, dwa podtypy `data class`) opisująca, jak ma być zbudowany łańcuch interceptorów i jak szczegółowo logowane żądania. Wyłącznie struktura danych (data classy), bez logiki wykonawczej.

### Endpointy
brak (brak URL-i, metod HTTP, nagłówków i szyfrowania — klasa nie buduje żądań)

### Modele danych
- `p00.h` -> `NetworkProfile` (baza abstrakcyjna, konstruktor prywatny; brak pól, brak metod) (plik: `p00/h.java`)
- `p00.h$Internal` -> `InternalNetworkProfile`: `loggingInterceptorLevel: tv.a$a` — poziom szczegółowości logowania HTTP (domyślnie `BODY` przy użyciu konstruktora syntetycznego); `equals`/`hashCode` tylko na poziomie (plik: `p00/h.java`)
- `p00.h$External` -> `ExternalNetworkProfile`: `loggingInterceptorLevel: tv.a$a` (domyślnie `BODY`), `additionalInterceptors: List<fv.w>` (dodatkowe interceptory wstrzykiwane przez profil, domyślnie pusta lista), `blockHttpCleartext: boolean` (domyślnie `true` — blokada HTTP cleartext); `equals` porównuje listy przez `fr.t.c(...)` (kolejnościowa równość list), `hashCode` = `((level.hashCode()*31) + list.hashCode())*31 + Boolean.hashCode(...)` (plik: `p00/h.java`)
- `tv.a$a` -> `okhttp3.logging.HttpLoggingInterceptor.Level` (NONE/BASIC/HEADERS/BODY) (plik: `p00/h.java`)
- `fv.w` -> `okhttp3.Interceptor` (typ elementów `additionalInterceptors`) (plik: `p00/h.java`)
- `fr.t` -> `okhttp3.internal.Util` (porównanie list `c(...)`) (plik: `p00/h.java`)
- `pq.v` -> `kotlin.collections.CollectionsKt` (`v.n()` = `emptyList()`) (plik: `p00/h.java`)
- Metadane klas oznaczone sufiksem `"network_release"` — nazwy zachowane przez R8 (plik: `p00/h.java`)

### Logika
- Konstruktory syntetyczne (z `$default`) ustalają wartości domyślne: `Internal` → poziom logowania `BODY`; `External` → poziom `BODY`, pusta lista interceptorów dodatkowych, `blockHttpCleartext = true` (plik: `p00/h.java`)
- `External.a()` (getter `additionalInterceptors`), `getBlockHttpCleartext()`, `getLoggingInterceptorLevel()`; `Internal.getLoggingInterceptorLevel()` (plik: `p00/h.java`)
- Obliczenia: brak przeliczeń; `hashCode`/`equals`/`toString` generowane dla obu data class (toString w formacie `Internal(loggingInterceptorLevel=…)`, `External(loggingInterceptorLevel=…, additionalInterceptors=…, blockHttpCleartext=…)`) (plik: `p00/h.java`)
- Retry/backoff, interwały, filtry, agregacje: brak
- Użycie: profile te są argumentem `p00.g.a(profile)` — składania łańcucha interceptorów (plik: `md/062_net.md`)
