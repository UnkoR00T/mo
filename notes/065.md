# 065_net.md

### Rola
`pc4/j.java` (część 2/2) to domknięcie tego samego modułu DI z `md/064_net.md`. Kluczowy element warstwy sieciowej: **dostawca adresu bazowego API oparty na use case**, a nie na stałym literaale; ponadto wybór implementacji magazynu dokumentów (kontenery szyfrowane vs. magazyn legacy) zależny od flagi funkcjonalnej.

### Endpointy
- **Adres bazowy API: brak danych** — wartość domeny i ścieżek nie występuje w kodzie; dostarczana dynamicznie przez use case (plik: `pc4/j.java`)
  - `pl.gov.coi.common.network.k s(getBaseUrlUseCase)` -> `f44.a` — implementacja dostawcy adresu bazowego (`c44.a getBaseUrlUseCase`), wstrzykiwana jako `ay.a baseUrlProvider` do `pl.gov.coi.common.network.w`/`t0` w `md/058_net.md` (plik: `pc4/j.java`)
- Metody HTTP, parametry, nagłówki, podpisywanie: brak w tej paczce (klasy fabrykujące zależności, nie wykonujące żądań) (plik: `pc4/j.java`)
- Pozostałe punkty wstrzykiwania (bez URL-i):
  - `z04.a w(identityManager, fileManager, currentTimeProvider, dateFormatter, masterKeyCipher, isFeatureEnabledUseCase, bytesCompressor, fileRegistry)` -> warstwa plików dokumentów z szyfrowaniem (plik: `pc4/j.java`)
  - `s10.a v(storageFactory)` -> `s10.c("mob_document_file_registry", storageFactory)` — rejestr plików dokumentów (plik: `pc4/j.java`)
  - `oc4.b t(context)` -> `oc4.b(context.getResources())` — dostawca zasobów (prawdopodobnie teksty błędów HTTP z R.string) (plik: `pc4/j.java`)
  - `t10.g u()` -> `pl.gov.mc.fringers.mobywatel.d` — implementacja interfejsu `t10.g` (plik: `pc4/j.java`)
  - `ch1.b0 x()` -> `pd4.e`, `qo2.a y(buildConfigRepository)` -> `pd4.f` (plik: `pc4/j.java`)

### Modele danych
- `pl.gov.coi.common.network.k` / `f44.a` -> `BaseUrlProviderImpl` (dynamiczny adres bazowy; implementacja interfejsu `ay.a`) (plik: `pc4/j.java`)
- `c44.a` -> `GetBaseUrlUseCase` (logika adresu bazowego — poza paczką; kluczowe miejsce do sprawdzenia pod kątem domen) (plik: `pc4/j.java`)
- `z04.a` / `nd4.p` -> `DocumentsStorage` (kontenery dokumentów: `f10.b masterKeyCipher` szyfrowanie, `az.a bytesCompressor` kompresja, `az.f fileManager`, `s10.a fileRegistry`) (plik: `pc4/j.java`)
- `pl.gov.coi.mobywatel.feature.legacy.storage.f` -> `LegacyDocumentsStorage` (wariant magazynu dokumentów, gdy flaga wyłączona; z `identityManager`, czasem i formatem daty) (plik: `pc4/j.java`)

- `f10.b` -> `MasterKeyCipher` (szyfr klucza głównego), `az.a` -> `BytesCompressor`, `az.f` -> `FileManager`, `cz.c` -> `StorageFactory` (plik: `pc4/j.java`)
- `oc4.b` -> `ResourcesProvider` (zasoby aplikacji) (plik: `pc4/j.java`)
- `ch1.b0` / `pd4.e` -> `FeatureConfigProvider`; `qo2.a` / `pd4.f` -> `EnvironmentProvider`/`AppConfigProvider` z `y04.a buildConfigRepository` (plik: `pc4/j.java`)

- `xj2.a` / `fd4.b` -> `AccessTokenProviderFactory`/`RepositoryFactory` z kontekstem (plik: `pc4/j.java`)
- `pc4.j` -> `NetworkModule` (ta sama klasa co `md/064_net.md`; tu metody `s`–`z`) (plik: `pc4/j.java`)

### Logika
- `w(...)` (wybór magazynu dokumentów): `isFeatureEnabledUseCase.a(b54.c.MOB_DB_CONTAINERS).booleanValue() ? new nd4.p(fileManager, currentTimeProvider, dateFormatter, masterKeyCipher, bytesCompressor, fileRegistry) : new pl.gov.coi.mobywatel.feature.legacy.storage.f(identityManager, currentTimeProvider, dateFormatter)` — ten sam feature flag co wybór magazynu tożsamości w `l(...)` (`md/064_net.md`): z flagą certyfikaty i dokumenty trzymane są w kontenerach szyfrowanych kluczem, bez flagi w magazynie legacy opartym na `identityManager` (plik: `pc4/j.java`)
- `s(getBaseUrlUseCase)`: adres bazowy jest **wyliczany w runtime** przez `c44.a` i przekazywany do fabryki klienta HTTP — brak zaszytego URL-a, domeny ani ścieżki w DEX-ie (plik: `pc4/j.java`)
- `v(storageFactory)`: rejestr plików pod jawną nazwą `mob_document_file_registry` (spójne z `mob_document_database_registry` z `md/064_net.md`) (plik: `pc4/j.java`)
- `x()`, `y()`, `u()`, `z()`: proste fabryki bez logiki (plik: `pc4/j.java`)
- Retry/backoff, interwały, filtry, agregacje: brak
