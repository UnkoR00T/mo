# 071_net.md

### Rola
Paczka zawiera wyłącznie kod bibliotek trzecich, bez logiki aplikacji:
- `pv/c` – wewnętrzna klasa biblioteki OkHttp (`OkHttpClient`), która przekierowuje logi `java.util.logging.Logger` na `android.util.Log` (m.in. dla `okhttp.OkHttpClient`, `okhttp.Http2`, `okhttp.TaskRunner`, `okhttp.MockWebServer`).
- `qd/a`, `qd/b` – implementacja loadera HTTP biblioteki Coil (`coil-network`) oparta na `java.net.HttpURLConnection` (pobranie `GET`, `disconnect()`, odczyt `getErrorStream`/`getInputStream`/`getContentType`).
- `rc/c` – `EngineInterceptor` biblioteki Coil (`coil-core`): dekodowanie `BitmapImage` i konwersja do Bitmap przed zastosowaniem transformacji.

### Endpointy
brak – brak interfejsu API aplikacji. `qd/b.a(String)` wykonuje `GET` na URL podanym przez caller’a, ale nie zawiera żadnego URL-a aplikacji ani nagłówków auth (plik: `qd/b.java:215-219`).

### Modele danych
- `qd.d` -> `ImageFetchResponse` (interfejs wyniku pobrania: `isSuccessful()`, `h3()` -> komunikat błędu, `j1()` -> `Content-Type`, `t1()` -> `InputStream`) – plik: `qd/a.java`
- `qd.a` -> `HttpUrlConnectionFetchResponse` – pole: `HttpURLConnection` – plik: `qd/a.java`
- `qd.f` -> `ImageFetcher` – `a(String url) : ImageFetchResponse` – plik: `qd/b.java`
- `pv.c` -> `AndroidLogger` – singleton; `configuredLoggers: CopyOnWriteArraySet<Logger>`, `knownLoggers: Map<String,String>` – plik: `pv/c.java`

### Logika
- `qd/a.isSuccessful()`: sukces = `responseCode / 100 == 2`; wyjątek `IOException` -> `false` (plik: `qd/a.java:182-188`).
- `qd/a.h3()`: przy błędzie buduje komunikat `"Unable to fetch " + URL + ". Failed with " + responseCode + "\n" + <treść errorStream>`; łapie `IOException | NullPointerException` i loguje przez `td.e.d` (plik: `qd/a.java:168-179`).
- `pv/c.c(...)`: poziom loggera dobierany z `Log.isLoggable(tag, 3)` -> `FINE`, inaczej `isLoggable(tag,4)` -> `INFO`, w przeciwnym razie `WARNING`; wyłącza handlery rodzica i dodaje własny handler `d.f162814a` (plik: `pv/c.java:57-70`).
- `pv/c.a(...)`: dzieli komunikat po `\n` i loguje w blokach po **4000 znaków** (limit Logcat), dopisując stack trace wyjątku (plik: `pv/c.java:77-104`).
- Brak retry/backoff.

### UI / metryki
brak – brak ekranów i wykresów; jedyne metryki to poziomy logowania.
