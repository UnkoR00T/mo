# 072_net.md

### Rola
Wyłącznie kod bibliotek trzecich, bez logiki aplikacji i bez warstwy sieciowej:
- `rc/e` – łańcuch interceptorów biblioteki Coil (`coil-core`): `RealInterceptorChain`, który po kolei wywołuje `rc.d` (interceptor obrazu), waliduje niezmienność `context`, `data`, `target`, `sizeResolver` i obsługuje wznowienie z coroutine (`isPlaceholderCached`, `eventListener`).
- `u4/AndroidFontResolveInterceptor`, `u4/e` – `androidx.compose.ui.text` (`FontFamilyResolver`): korekta wagi czcionek o `fontWeightAdjustment` z zasobów Androida.

### Endpointy
brak – żadnych URL-i, metod HTTP ani nagłówków. `rc/e` operuje wyłącznie na `ImageRequest` (plik: `rc/e.java`).

### Modele danych
- `rc.e` -> `RealInterceptorChain` (implementacja `rc.d.a`) – pola: `initialRequest: ImageRequest`, `interceptors: List<rc.d>`, `index: int` (indeks aktualnego interceptora), `request: ImageRequest`, `size: Size`, `eventListener: jc.j`, `isPlaceholderCached: boolean` – plik: `rc/e.java`
- `rc.e$a` -> `ContinuationState` (wewnętrzna klasa kontynuacji korutyny, extends `vq.d`) – plik: `rc/e.java:52-73`
- `rc.d` -> `Interceptor` (interfejs: `a(chain, continuation)`), `rc.d$a` -> `Interceptor.Chain` – plik: `rc/e.java`
- `u4.AndroidFontResolveInterceptor` -> `FontWeightResolveInterceptor` (data class) – pole: `fontWeightAdjustment: int` – plik: `u4/AndroidFontResolveInterceptor.java`
- `zc.ImageRequest`, `zc.i`, `zc.k`, `kc.j`, `ad.Size` – modele Coil.

### Logika
- Łańcuch interceptorów: stan kontynuacji ma 2 fazy (`i16 == 0` -> wywołanie `interceptors.get(index).a(...)` z łańcuchem o `index+1`; `i16 == 1` -> wznowienie); wywołanie `resume` przed `invoke` rzuca `IllegalStateException("call to 'resume' before 'invoke' with coroutine")` (plik: `rc/e.java:136-175`).
- Walidacja po powrocie z interceptora – `IllegalStateException`, gdy zmieniono: `context` ("cannot modify the request's context"), `data` (`k.f234180a` = null → "cannot set the request's data to null"), `target`, `sizeResolver` ("Use `Interceptor.Chain.withSize` instead") (plik: `rc/e.java:86-100`).
- Sygnatura `take`/sentinel: `uq.b.e()` jako marker `COROUTINE_SUSPENDED` – gdy interceptor zwróci ten sam obiekt, łańcuch zwraca go bez dalszej walidacji (plik: `rc/e.java:150-174`).
- Korekta wagi czcionki: `fontWeight + fontWeightAdjustment`, ograniczona (`coerceIn`) do zakresu **1..1000**; korekta pomijana gdy adjustment == 0 lub `Integer.MAX_VALUE` (brak korekty w systemie) (plik: `u4/AndroidFontResolveInterceptor.java:204-208`).
- `u4/e.a(Context)` tworzy interceptor z adjustment odczytanym z zasobów Androida (`e0.a(context)`) (plik: `u4/e.java:239-242`).
- Brak retry/backoff/interwałów.

### UI / metryki
brak – brak wykresów i kafelków. Jedyne „metryki” to poziomy logowania Coil (`eventListener`, `isPlaceholderCached` jako flaga cache placeholdera).
