# 074_net.md

### Rola
Implementacja transportu HTTP backendu Volley (`wd.h`) — klient oparty o `HttpURLConnection` obsługujący mapowanie metody HTTP na `HttpURLConnection.setRequestMethod`, nagłówki, timeouty i opcjonalny własny `SSLSocketFactory`. Kod biblioteczny (Volley), bez logiki domenowej aplikacji mObywatel.

### Endpointy
brak — klasa transportowa bez zdefiniowanych URL-i. Wspiera metody GET/POST/PUT/DELETE/HEAD/OPTIONS/TRACE/PATCH na podstawie `vd.n.w()`; URL bierze z `vd.n.I()`.

### Modele danych
brak (tylko wewnętrzne: `wd.h.a` -> `HttpResponseStream` (FilterInputStream zamykający też `HttpURLConnection`), `wd.h.b` -> pusty interfejs `SslSocketFactoryProvider` (marker), `vd.g` -> para nagłówek/nagłówki odpowiedzi, `wd.a` -> `NetworkResponse` z polami `responseCode` i `headers`).

### Logika
- Timeout: connect i read ustawiane na tę samą wartość `nVar.G()` (ms). `wd/h.java:107-110`
- `setUseCaches(false)`, `setDoInput(true)`, `setInstanceFollowRedirects` z globalnego `HttpURLConnection.getFollowRedirects()`. `wd/h.java:111-115`, `wd/h.java:149-153`
- TLS: dla `https` podstawia własny `SSLSocketFactory` jeśli został przekazany w konstruktorze (możliwość custom trust = potencjalny punkt wstrzyknięcia konfiguracji TLS przez aplikację); brak pinowania certyfikatów w kodzie. `wd/h.java:113-115`
- Nagłówki: scala mapa przekazana z zewnątrz oraz `nVar.v()`, po czym ustawia wszystkie przez `setRequestProperty`. `wd/h.java:120-129`
- Body: `Content-Type` ustawiany tylko jeśli nie ma go w nagłówkach, wartość z `nVar.r()`; `doOutput(true)`. `wd/h.java:59-67`
- Klasyfikacja odpowiedzi: sukces tylko dla kodu 3xx (nie 304) lub 4xx; `responseCode == -1` -> IOException. `wd/h.java:89-94`
- Odczyt: najpierw `getInputStream()`, przy IOException fallback `getErrorStream()`. `wd/h.java:97-103`
- Brak logiki retry/backoff w tej klasie.

### UI / metryki
brak.

### Brakujące klasy
- `vd.a`, `vd.g`, `vd.n` (interfejs żądania: `I()` URL, `v()` nagłówki, `r()` Content-Type, `q()`/`z()` body, `w()` typ metody, `G()` timeout) — pakiet `vd`, najpewniej rdzeń biblioteki Volley.
- `wd.a`, `wd.f` — baza transportu i kontener odpowiedzi Volley.
