# 096_model.md

### Rola
Paczka `ch.*` - zestaw `Parcelable.Creator` do modeli aplikacji zapisanych jako SafeParcelable (`kg.a` = SafeParcelable, `kg.d.SAFE_PARCELABLE_NULL_STRING`). Każdy plik (oprócz `ch/fl.java`) to wyłącznie boilerplate `createFromParcel`/`newArray`; jedyny właściwy model to `ch/fl.java`. Klasy docelowe (`kl`, `ra`, `ll`, `sb`, `tc`, `ud`, `ve`, `xf`) leżą w innych paczkach (`098`, `100`, `101`, `102`).

### Logika
- Wzorzec odczytu SafeParcelable: `kg.b.C(parcel)` = zapamiętaj `dataSize()`; pętla `while (parcel.dataPosition() < size)` z `t()` = odczyt tagu, `n()` = indeks pola; `h` = `String`, `v` = `int`, `q` = `double`, `i` = `String[]`, `B` = pomijanie nieznanych pól; zamknięcie `kg.b.m(parcel, size)` (096:26-41 i analogicznie w pozostałych).
- Zapis (tylko `ch.fl`): blok `kg.c.a` ... `kg.c.b`, pola po kolei w kolejności tagów (096:372-377).
- Wartości domyślne przy braku tagu: `null` dla `String`/`String[]`, `0` dla `int`, `0.0` dla `double` (096:110-111, 285-286).
