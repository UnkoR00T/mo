# 105_model.md

### Rola
Model danych karty emeryta/renta (legitymacja ZUS) przekazywany przez `Parcelable` (Intent/Bundle między ekranami). Nie zawiera żadnej logiki ani sieci - czysty value-object z 8 polami i pełnym `equals`/`hashCode`/`toString`.

### Endpointy
brak

### Modele danych
`ci2.PensionerCardData` -> **PensionerCardData** (legitymacja osoby pobierającej świadczenie z ZUS). Plik: `ci2/PensionerCardData.java`.

`ci2.PensionerCardData$a` (`C0701a`) -> **CREATOR** (`Parcelable.Creator`): `createFromParcel` czyta kolejno 6×String + `readSerializable()` (Date) + String; `newArray` tworzy tablicę. `describeContents()` = 0 (brak plików). `writeToParcel` zapisuje w kolejności odwrotnej do odczytu.

### Logika
- `equals`: porównuje wszystkie 8 pól przez `t.c(...)` (kotlinx `Intrinsics.areEqual` / null-safe equals) (`ci2/PensionerCardData.java:115`).
- `hashCode`: klasyczny mnożnik `* 31` po kolei, od `number` do `department`, null = 0 (`ci2/PensionerCardData.java:141`).
- `toString`: `PensionerCardData(number=..., firstName=..., secondName=..., lastName=..., pesel=..., type=..., expiredData=..., department=...)` - używany prawdopodobnie w logach diagnostycznych (nie zawiera maskingu PESELu).
- Brak przeliczeń jednostek, agregacji, interwałów odświeżania.

### UI / metryki
Sam plik nie zawiera UI. Dane (imię, nazwisko, PESEL, numer, data ważności, jednostka ZUS) są dostępne przez getery `getNumber/getFirstName/getSecondName/getLastName/getPesel/getType/getExpiredData/getDepartment`, co wskazuje na wyświetlanie danych karty na ekranie informacji o karcie emeryta. Brak wykresów/kafelków/formatowania liczb.

### Brakujące klasy
- `vl.c` - adnotacja używana na polach (`ci2/PensionerCardData.java:27`). Prawdopodobnie `kotlinx.serialization.SerialName` (adnotacja jest zaciemniona), pakiet `vl` nie występuje w przejrzanych paczkach. Jeśli to `@SerializedName` Gson, to `PensionerCardData` jest parsowany Gsonem.
- `fr.t` - `kotlin.jvm.internal.Intrinsics` (null-safe `equals`), biblioteka (ci2/PensionerCardData.java:16).
