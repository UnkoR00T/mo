# 107_model.md

### Rola
Dwie niezależne rzeczy w jednej paczce:
1. `cz2/a.java` - zapieczętowana (sealed) klasa **celu nawigacji** `QualifiedSignatureDestination` dla modułu kwalifikowanego podpisu (`qualifiedsignature_release`). Trzy warianty: Deeplink (z tokenem), Main, QrScanner. Wszystkie `Parcelable`, przekazywane jako `TAG_QUALIFIED_SIGNATURE_DESTINATION` w Bundle'zie i jako `startDestination` w ViewModelu.
2. `d8/a.java` - `ClearKeyUtil` z biblioteki Androida (AndroidKeyStore / `media` DRM clear key) - **kod biblioteki**, nie aplikacji.

### Endpointy
brak

`d8.a` -> **ClearKeyUtil** (biblioteka Androida, `classes3.dex`), plik `d8/a.java`:
- `a(byte[])` -> **adjustResponse(byte[])**: na API >= 27 (Android 8.1) zwraca wejście bez zmian; poniżej koduje/dekoduje przez `o0.p0`/`o0.G` (`:198`).
- `b(byte[])` -> **adjustRequest(byte[])**: dla API < 27 przebudowuje JSON z kluczem `keys`, mapując `k` i `kid` przez Base64 URL-safe <-> standardowy, `kty` kopiowane 1:1 (`:202`).
- `c(String)` -> base64url -> base64 (`+`->`-`, `/`->`_`), `d(String)` -> odwrotnie (`:231`, `:235`).
- Logowanie błędu pod tagiem `"ClearKeyUtil"`: `"Failed to adjust response data: <json>"` z całym JSON-em w logu (`:226`).

### Logika
`cz2`: brak logiki - brak przeliczeń, agregacji, interwałów. Jedyna mechanika to dyskryminacja wariantu sealed przez serializację Parcelable (znaczniki `int 1` dla obiektów, `String` dla Deeplink).

`d8`: realna logika formatowania - zamiana alfabetu Base64 dla zgodności z WebCrypto na API < 27 oraz ręczna rekonstrukcja JSON (StringBuilder) zamiast ponownej serializacji obiektu.

### UI / metryki
Z `cz2.a` wynika nawigacja: po zakończeniu kwalifikowanego podpisu aplikacja przekazuje `destination` do `SharedViewModel` (`startDestination`, `m2.r` - navigation, widoczne w `md/289_ui.md` i `md/198_model.md`) i zapisuje go w Bundle pod kluczem `TAG_QUALIFIED_SIGNATURE_DESTINATION` (`md/198_model.md:139`). `ToIdentityConfirmation(destination)` (`md/376_ui.md:145`) to ekran potwierdzenia tożsamości posiadający cel. Przykładowe użycie: `vi.INSTANCE.a(cz2.a.b.f38819a)` - po podpisie powrót do `Main` (`md/406_ui.md:398`). Wariant `QrScanner` = ścieżka "skanuj kod QR" zamiast deep linka.

`d8` nie ma UI (wewnętrzna normalizacja DRM).

- `o2`/`sd4.vi`/`id4.i`/`dz2.x`/`m2.r` - konsumenci `cz2.a` poza tym pakietem (nawigacja, Bundle), poza zakresem analizy.
