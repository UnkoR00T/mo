# 108_model.md

### Rola
Cała paczka to **kod bibliotek**, brak modeli domenowych aplikacji mObywatel:
1. `di/c.java` - `WalletClientImpl` (Google Wallet / play-services-wallet): klient IPC do `com.google.android.gms.wallet.internal.IOwService`.
2. `e6/b.java` - `androidx.core.os.BundleCompat` (bezpieczne `getParcelable`/`getParcelableArrayList` z klasą, API 33+).
3. `e6/c.java` - `androidx.core.os.BundleKt` (`bundleOf(vararg Pair)`), rdzeń `core-ktx`.
4. `eg/d.java` - `CollectForDebugParcelable` (Firebase JobIntent / `kg.a`) - flagi okna zbierania danych.

### Endpointy
brak sieciowych. Jest tylko wiązanie do usługi systemowej:
- Binder: `com.google.android.gms.wallet.service.BIND`, interfejs `com.google.android.gms.wallet.internal.IOwService` (`di/c.java:70`, `:75`).
- Klucze Bundle: `com.google.android.gms.wallet.EXTRA_ENVIRONMENT`, `EXTRA_USING_ANDROID_PAY_BRAND`, `EXTRA_BUYER_ACCOUNT` (`Account(str2, "com.google")`), `EXTRA_THEME`, `EXTRA_WALLET_CLIENT_ID`, `EXTRA_USING_AUTO_RESOLVABLE_RESULT`, `androidPackageName` (`di/c.java:51`).
- Brak auth/headers/podpisywania - to lokalne IPC do GMS.

### Logika
- `di.c.n0()` -> składa Bundle przez `j0(...)` z `L.getPackageName()` i `N` (`:64`).
- `di.c.p(IBinder)` -> `queryLocalInterface("com.google.android.gms.wallet.internal.IOwService")`, w razie niepowodzenia opakowuje w proxy `di.d` (`:91`).
