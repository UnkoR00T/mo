# 111_model.md

### Rola
Paczka **wyłącznie biblioteczna** - kolejne Parcelable z warstwy `com.google.android.gms` (wyniki detektora: twarz/dokument/geometria). Brak modeli domenowych aplikacji mObywatel i brak endpointów.

### Endpointy
brak

Struktura (7 liczb zmiennoprzecinkowych + `Rect` + lista punktów + lista elementów `qe`) odpowiada wynikowi detektora twarzy/dokumentu z GMS Vision; konkretne nazwy semantyczne nie da się ustalić z kodu.

### Logika
Wyłącznie serializacja Parcelable (tagi, `kg.c` zapis / `kg.b` odczyt, pomijanie nieznanych pól, wartości domyślne 0/false/null). Brak obliczeń, konwersji jednostek, filtrów, agregacji i interwałów odświeżania.

### UI / metryki
Brak UI w tej paczce. Gettery `i()`, `C()`, `r()`, `m()`, `y()`, `h()`, `p()`, `u()`, `H()`, `E()` udostępniają wynik detektora konsumentowi spoza paczki (prawdopodobnie do rysowania/raportowania rozpoznania), ale nie widać tu żadnego widoku ani metryki.

### Brakujące klasy
- `eh.nd` - CREATOR dla `eh.mc` (nie w tej paczce).
- `qe` - element listy w `eh.je.items` (brak definicji w przejrzanych paczkach).
- `kg.a`, `kg.b`, `kg.c` - biblioteczny helper Parcelable.
- Semantyczne nazwy pól `eh.he`, `eh.mc`, `eh.je` nie do odtworzenia - konsumenci spoza przejrzanych paczek.
