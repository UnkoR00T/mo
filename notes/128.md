# 128_model.md

### Rola
Wszystkie pliki to biblioteka CTAP2/FIDO2 (authenticator): modele żądań i odpowiedzi WebAuthn (`GetInfo`, wybór authenticatora, credential descriptor, typy z `Uri` do `icon`/`rpId`). Nic z logiki aplikacji mObywatel.

### Endpointy
brak (modele lokalne CTAP2, brak HTTP)

### Modele danych
- `ii.e` -> AuthenticatorSelectionCriteria: `b()` = `ii.e.b` (enum kontenera: CONTAINMENT_UNSPECIFIED/WITHIN/OUTSKIRTS/NEAR), `c()`/`d()`/`e()`/`f()` = String (obligatoryjne kryteria: authenticatorAttachment, residentKey, requireResidentKey, userVerification); builder `ii.e$a` [ii/e.java]
- `ii.f` -> UserVerificationRequirement (String): `b()` = wymaganie (walidacja: nazwa niepusta), `c()`/`d()` = String (userVerification + display preference); builder `ii.f$a` (`b(str)`, `c(str)`) [ii/f.java]
- `ii.f0` (extends `ii.g3`) -> PublicKeyCredentialRpEntity: `b()` = `ii.o` (iconka/RP), `c()`/`d()` = String (nazwa wyświetlana RP), `e()` = `android.net.Uri` (ikona), `f()` = `ii.o`; builder `ii.f0$a` (`b/f` z `o`, `c/d` String, `e(Uri)`), implementacja `ii.y1` [ii/f0.java]
- `ii.e0` -> Duration: `a()` = String (jednostka), `b()` = Integer (nano), `c()` = Long (value); fabryka `d(String, Long, Integer)` przez builder `v1` [ii/e0.java]
- `ii.d6` -> implementacja z polem `int` (`extends q2`), parcelowana ręcznie; CREATOR z `c6` [ii/d6.java]
- `ii.e5` -> implementacja `extends s1`, `ii.f6` -> `extends s2`, `ii.f4` -> `extends t7` [ii/e5.java, ii/f6.java, ii/f4.java]
- `ii.d7`, `ii.e4`, `ii.e6`, `ii.e7`, `ii.f5`, `ii.f7` -> `Parcelable.Creator` dla powyższych implementacji [ii/d7.java, ii/e4.java, ii/e6.java, ii/e7.java, ii/f5.java, ii/f7.java]

### Logika
- `ii.e0$a.a()`: walidacja spójności `value`/`nano` - dodatnia wartość wymaga nano >= 0, ujemna nano <= 0 (`zj.p.l`), w przeciwnym razie `IllegalArgumentException` [ii/e0.java]
- `ii.e0.d(...)`: fabryka statyczna, ustawia jednostkę/value/nano i od razu waliduje przez `a()` [ii/e0.java]
- `ii.e$a.b(ii.b)`: builder przyjmuje obiekt kryteriów zamiast pojedynczych flag (rozszerzenie selekcji authenticatora) [ii/e.java]
- `ii.f0$a.b/f(ii.o)`: dwa niezależne sloty typu `ii.o` (prawdopodobnie `icon` i `rp`) [ii/f0.java]
- `ii.f$a.a()`: `zj.p.e` - nazwa nie może być pusta [ii/f.java]
