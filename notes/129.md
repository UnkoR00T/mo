### Rola
Modele danych **Google Places / Maps** (`ii.g0` = godziny otwarcia z flagą open-now i `PlaceBusinessStatus` typu ACCESS/BREAKFAST/TAKEOUT, `ii.h` = `AddressComponent` ze stylami `SpannableString`, `ii.h0` = komponent adresu z 8 flagami typu `l0.a`). Zero logiki aplikacji mObywatel.

### Endpointy
brak w tej paczce (wywołanie Places API może być w innej paczce)

### Modele danych
- `ii.g0` -> OpeningHours: `b()` = `ii.g0$b` (status biznesowy: ACCESS, BREAKFAST, BRUNCH, DELIVERY, DINNER, DRIVE_THROUGH, HAPPY_HOUR, KITCHEN, LUNCH, ONLINE_SERVICE_HOURS, PICKUP, SENIOR_HOURS, TAKEOUT; Parcelable po `name()`), `c()` = `List<ii.j0>` (godziny otwarcia - okresy), `d()` = `List<ii.w0>` (special days), `e()` = `List<String>` (teksty dni tygodnia), `f()` = Boolean (czy otwarte teraz), `g()`/`h()` = `java.time.Instant` (godzina otwarcia/zamknięcia); builder `ii.g0$a` (`b(status)`, `c/d/e(listy)`, `f(Boolean)`, `g/h(Instant)`) [ii/g0.java]
- `ii.g` -> zbiór wymagań weryfikacji użytkownika: `a()` = `List<ii.f>` (lista UserVerificationRequirement, filtr `ak.n0.v`); fabryka `b(List<f>)` [ii/g.java]

### Logika
- `ii.h.m(text, ranges, style)`: nakłada `CharacterStyle` na wskazane przedziały (`u6.a()` = start, `u6.b()` = długość), pomijane gdy tekst pusty, styl null lub lista pusta [ii/h.java]
- `ii.h$a.a()`: `ak.n0.v` na cztery listy (kompaktowanie/filtracja pustych wartości) [ii/h.java]
- `ii.h.a(String)`: fabryka ustawiająca puste listy i puste stringi, by builder był spójny [ii/h.java]
- `ii.g0$a.a()`: walidacja `TextUtils.isEmpty` na każdym tekście dnia tygodnia ("WeekdayText must not contain null or empty values."), potem `ak.n0.v` na listach godzin/special days/weekdayText [ii/g0.java]
- `ii.g0$a()` (fabryka): tworzy `ii.a2` z trzema pustymi listami [ii/g0.java]

### UI / metryki
`ii.h.d(CharacterStyle)` / `e(CharacterStyle)` zwracają `SpannableString` - czyli podświetlenie dopasowanych fragmentów adresu w UI (styl przekazywany z warstwy widoku). Brak wykresów/tilek w tej paczce.
