# 131_model.md

### Rola
Ostatnie modele biblioteki **Places** (`ii.k` = recenzja/obcena z `Instant`, `ii.k0` = `PlacePhoto` z PhotoReference i rozmiarem, `ii.k3/k4/k5` implementacje, `ii.l` = podmiot powiązany z `ii.m`). Bez logiki aplikacji, bez endpointów.

### Endpointy
brak

### Modele danych
- `ii.k` -> Review: `b()` = `java.time.Instant` (data recenzji, nullable), `c()` = Integer (ocena autora, nullable), `d()` = Integer (wynik/numer, wymagane), `e()` = `Double` (średnia ocena, wymagana), `f()` = Integer (nullable), `g()` = `ii.r` (autor/właściciel, wymagany); fabryka `a(ii.r, Double, Integer)` przez builder `ii.q7` [ii/k.java]
- `ii.k0` -> PlacePhoto: `b()` = String (pusta domyślnie), `c()` = `ii.g` (listy wymagań), `d()`/`e()` = `Uri` (dwa URI zdjęcia), `f()` = int (height, wymagane >= 0), `g()` = int (width, wymagane >= 0), `h()` = String (PhotoReference, wymagany niepusty), `i()` = String (nullable); builder `ii.k0$a`, implementacja `ii.i2`; fabryka `a(String photoReference)` ustawia height=width=0 [ii/k0.java]
- `ii.k3` (extends `s3`) -> implementacja: `b()` = String, `c()` = String (nullable), `d()` = `List` (parcelowany `writeList`) [ii/k3.java]
- `ii.k4` -> `Parcelable.Creator` czytający `(String?, String?, ArrayList<ii.o>, ArrayList<ii.o>)` -> `ii.l4` [ii/k4.java]
- `ii.k5` (extends `z1`) -> implementacja `(ii.o, ii.o, Uri, String?, String?)`, parceluje kolejno `f()`, `b()`, `e()` jako Parcelable oraz dwa nullable String [ii/k5.java]
- `ii.l` -> Place/opis podmiotu: `b()` = `ii.m` (nullable), `c()`/`d()` = String (nullable); builder `ii.l$a`, implementacja `ii.s7` [ii/l.java]

### Logika
- `ii.k0$a.a()`: walidacja - width >= 0 i height >= 0 (`zj.p.h`) oraz PhotoReference niepusty (`zj.p.e`, komunikat "PhotoReference must not be empty.") [ii/k0.java]
- `ii.k0.a(str)`: fabryka ustawia photoReference, wymiary 0/0 i pusty string [ii/k0.java]
- Parcelowanie nullable: `writeInt(1)` = null, `writeInt(0)` + wartość [ii/k3.java, ii/k5.java]
