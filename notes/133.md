### Rola
Kolejne modele biblioteki **Places** (`ii.m0` = wynik rankingu prawdopodobieństwa typu podmiotu, `ii.m`/`ii.n`/`ii.n0` = typy pomocnicze opisów, reszta implementacji Parcelable). Bez logiki aplikacji i bez endpointów.

### Endpointy
brak

### Modele danych
- `ii.m0` (@Deprecated) -> SimilarPlace/likelihood: `a()` -> double (likelihood), `b()` -> `ii.l0` (obiekt Place, wymagany); fabryka `c(Place, double)` przez `ii.z5` [ii/m0.java]
- `ii.m` -> PlaceIcon/zasób graficzny: `b()`/`d()`/`e()` = String (url maski, kolor tła, kolor?), `c()` = `Uri`; builder `ii.m$a`, implementacja `ii.u7` [ii/m.java]
- `ii.n` -> Para tekstowa (dwa wymagane String, `b()`/`c()`), fabryka `a(String, String)` przez `ii.w7` [ii/n.java]
- `ii.n0` -> Para tekstowa nullable (`b()`/`c()` = String), builder `ii.n0$a`, implementacja `ii.n2` [ii/n0.java]
- `ii.l4` (extends `b1`) -> implementacja `(String?, String?, List, List)`; parceluje dwa nullable String i dwie listy [ii/l4.java]
- `ii.m3` -> implementacja z pojedynczym `ArrayList` (CREATOR `l3`) [ii/m3.java]
- `ii.m4`, `ii/m5.java`, `ii/m6.java`, `ii/l5.java`, `ii/l6.java`, `ii/n3.java`, `ii/n4.java`, `ii/n5.java`, `ii/n6.java` -> implementacje Parcelable + ich `Parcelable.Creator` [ii/l5.java, ii/l6.java, ii/m4.java, ii/m5.java, ii/m6.java, ii/n3.java, ii/n4.java, ii/n5.java, ii/n6.java]

### Logika
- `ii.m0.c(place, likelihood)`: walidacja zakresu likelihood 0.0..1.0 (`ak.q1.d(0.0, 1.0)` + `zj.p.n`, komunikat "Likelihood must not be out-of-range..."), potem tworzy `ii.z5` [ii/m0.java]
- Parcelowanie nullable: `writeInt(1)` = null, inaczej `writeInt(0)` + `writeString` [ii/l4.java]
- Listy parcelowane przez `parcel.writeList(...)` [ii/l4.java]
