# 160_model.md

### Rola
Paczka zawiera wyłącznie dwie klasy `Parcelable.Creator` biblioteki `play-services-location`: `kh/m` tworzy `NetworkLocationStatus` (`kh/l`), a `kh/p` tworzy `CurrentLocationRequest` (`kh/a`). Kod boilerplate odczytu pól z `Parcel` (przez `kg.b` z paczki 157), bez logiki aplikacji.

### Endpointy
brak

### Modele danych
- `kh.m` -> `NetworkLocationStatus.CREATOR` (`Parcelable.Creator`; `newArray` -> `new l[i15]`) (plik: `kh/m.java`)
  - `createFromParcel`: id `1` -> `int` (`kg.b.v`) = `wifiStatus`; id `2` -> `int` = `cellStatus`; id `3` -> `long` (`kg.b.y`) = `elapsedTimeNanos`; id `4` -> `long` = `systemTimeMillis`; inne -> `kg.b.B` (skip) (plik: `kh/m.java`)
  - wartości domyślne przed pętlą: `wifiStatus = 1`, `cellStatus = 1`, `elapsedTimeNanos = -1`, `systemTimeMillis = -1` (plik: `kh/m.java`)
  - wynik: `new l(wifiStatus, cellStatus, elapsedTimeNanos, systemTimeMillis)` (plik: `kh/m.java`)
- `kh.p` -> `CurrentLocationRequest.CREATOR` (`Parcelable.Creator`; `newArray` -> `new a[i15]`) (plik: `kh/p.java`)
  - `createFromParcel` (switch po `kg.b.n(iT)`): `1` -> `long` = `maxAgeMillis`; `2` -> `int` = `priority`; `3` -> `int` = `quality`; `4` -> `long` = `durationMillis`; `5` -> `boolean` = `bypass`; `6` -> `WorkSource` (przez `WorkSource.CREATOR`); `7` -> `int` = `maxUpdateAgeMillis`; `9` -> `zg.f0` = `impersonation`; `8` i inne -> `kg.b.B` (skip) (plik: `kh/p.java`)
  - wartości domyślne przed pętlą: `maxAgeMillis = Long.MAX_VALUE`, `priority = 0`, `quality = 102`, `durationMillis = Long.MAX_VALUE`, `bypass = false`, `maxUpdateAgeMillis = 0`, `WorkSource()` pusty, `impersonation = null` (plik: `kh/p.java`)
  - wynik: `new a(maxAgeMillis, priority, quality, durationMillis, bypass, maxUpdateAgeMillis, workSource, impersonation)` (plik: `kh/p.java`)

### Logika
- Odczyt pozycji końca obiektu: `kg.b.C(parcel)` (nagłówek `"OM"`), pętla `while (parcel.dataPosition() < end)`, po pętli walidacja nadmiarowego odczytu `kg.b.m(parcel, end)` (plik: `kh/m.java`, `kh/p.java`)
- Pola odczytane po identyfikatorze z `kg.b.n(iT)` (16 dolnych bitów); nieznane identyfikatory pomijane przez `kg.b.B(parcel, iT)` (plik: `kh/m.java`, `kh/p.java`)
- `maxAgeMillis` i `durationMillis` domyślnie `Long.MAX_VALUE` (= brak limitu) w CREATOR, `quality` domyślnie `102`; wartości domyślne zapisane w `Parcel` przez `kh.a.writeToParcel` zostaną nadpisane przez odczyt (brak rozróżnienia „brak pola” vs „wartość domyślna”) (plik: `kh/p.java`)
- Brak przeliczeń, agregacji, interwałów poza stałymi `102`/`10000`/`MAX_VALUE`.
