# 175_model.md

### Rola
`p006NUl/j.java` to `Parcelable` opisujący **żądanie uruchomienia `IntentSender` z wypełnieniem Intent** (`androidx.activity.result.contract.ActivityResultContracts.IntentSenderRequest`) wraz z builderem. Klasa biblioteczna androidx.activity, brak logiki aplikacji.

### Endpointy
brak

### Modele danych
- `p006NUl.j` -> `IntentSenderRequest implements Parcelable` (plik: `p006NUl/j.java`)
  - `intentSender: android.content.IntentSender` - nadawca do uruchomienia (plik: `p006NUl/j.java`)
  - `fillInIntent: android.content.Intent` - Intent uzupełniający (`fillIn`) wysyłany do nadawcy (plik: `p006NUl/j.java`)
  - `flagsMask: int` - maska flag Intent (`Intent.fillIn` flags) (plik: `p006NUl/j.java`)
  - `flagsValues: int` - wartości flag Intent (plik: `p006NUl/j.java`)
  - `CREATOR: Parcelable.Creator<j>` (plik: `p006NUl/j.java`)
  - `describeContents(): int` -> `0` (brak pól plików) (plik: `p006NUl/j.java`)
  - `writeToParcel(Parcel, int)` -> `writeParcelable(intentSender)`, `writeParcelable(fillInIntent)`, `writeInt(flagsMask)`, `writeInt(flagsValues)` (plik: `p006NUl/j.java`)
  - `j(Parcel)` -> odczyt w kolejności: `IntentSender`, `Intent`, dwa `int` (plik: `p006NUl/j.java`)
  - gettery: `getIntentSender()`, `getFillInIntent()`, `getFlagsMask()`, `getFlagsValues()` (plik: `p006NUl/j.java`)
- `p006NUl.j$a` -> `Builder` żądania `IntentSenderRequest` (plik: `p006NUl/j.java`)
  - `intentSender: IntentSender` - nadawca (z `IntentSender` lub z `PendingIntent.getIntentSender()`) (plik: `p006NUl/j.java`)
  - `fillInIntent: Intent` - Intent uzupełniający, domyślnie `null` (plik: `p006NUl/j.java`)
  - `flagsMask: int` - maska flag, domyślnie `0` (plik: `p006NUl/j.java`)
  - `flagsValues: int` - wartości flag, domyślnie `0` (plik: `p006NUl/j.java`)
  - `b(Intent)` -> ustawia `fillInIntent`, zwraca `this` (plik: `p006NUl/j.java`)
  - `c(int values, int mask)` -> ustawia `flagsValues = values`, `flagsMask = mask`, zwraca `this` (plik: `p006NUl/j.java`)
  - `a()` -> `new j(intentSender, fillInIntent, flagsMask, flagsValues)` (plik: `p006NUl/j.java`)
- `p006NUl.j$b` -> `Parcelable.Creator<IntentSenderRequest>`: `createFromParcel` -> `new j(inParcel)`, `newArray(size)` -> `new j[size]` (plik: `p006NUl/j.java`)

### Logika
- Serializacja 4-elementowa: 2 obiekty `Parcelable` + 2 `int` flag `fillIn`; brak obliczeń, walidacji ani wartości domyślnych poza `null`/`0` (plik: `p006NUl/j.java`)
- Budowanie flag: `c(values, mask)` kolejność argumentów jest odwrotna względem pól (`flagsValues` przed `flagsMask`) (plik: `p006NUl/j.java`)
