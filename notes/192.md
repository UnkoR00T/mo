# 192_model.md
### Rola
Fragment Compose `SafeBusFeatureFragment` (`sd4/ij.java`) - host ekranu bezpiecznego autobusu (Safe Bus / komunikaty o zagrożeniu w transporcie). Przyjmuje opcjonalny deep link, przekazuje go do nawigacji po gotowosci grafu i po powrocie z ekranu przechodzi do tagu "SafeBusFragment".

### Endpointy
brak (brak HTTP; deep link obsluzony przez `NavController.F(Uri)`, URI z argumentu)

### Modele danych
`sd4.ij` -> SafeBusFeatureFragment (ComposeView, `sd4/ij.java`)
- `deeplink` (`M0`): Uri - deep link do nawigacji (klucz Bundle `"deepLinkUri"`)
- `fragmentNavigator` (`L0`): `rh2.a` - FragmentNavigator (opcjonalny)
- `O0`: int = 8 - stala
- `N0` (`INSTANCE`): Companion - fabryka; metadane: `KEY_DEEP_LINK`, `TAG_SAFE_BUS`
- `s03.a` - interfejs/host nawigacji ekranu Safe Bus (wybierany w `S1`), `s03.d.f177175a` / `s03.e.f177177a` - dwa warianty hosta
- `f00.s` -> DestinationNavigator (argument callbacku `onNavGraphReady`, `pl.gov.coi.common.navigation.DestinationNavigator`) (`sd4/ij.java:63`)
- `r03.m0` - zawartosc nawigacji Safe Bus (`z(aVar, onNavGraphReady, onResult, rVar, 0)`)

### Logika
`x0(Bundle)`: odczyt `deepLinkUri` z argumentow (Uri), null gdy brak Bundle (`sd4/ij.java:193`).
`g2(f00.s)`: jesli deep link != null -> `destinationNavigator.getNavController().F(uri)` (`sd4/ij.java:124`).
`c2(ij)`: po `onResult` -> `fragmentNavigator.c("SafeBusFragment")` (powrot na ekran bezpiecznego autobusu) (`sd4/ij.java:112`).
`S1(...)`: wybor `s03.a` przez `w0.h0.a(rVar, 0)` - `true` -> `s03.d.f177175a`, `false` -> `s03.e.f177177a` (`sd4/ij.java:145`).
`b2(...)`: callbacki `onNavGraphReady` i wynik pamietane w `remember`; oddanie do `r03.m0.z(...)` (`sd4/ij.java:78`).
`Companion.a(Uri)`: `deepLinkUri` w Bundle tylko gdy niepusty (`sd4/ij.java:46`).
