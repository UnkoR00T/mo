# 193_model.md
### Rola
Fragment Compose `SettingsFeatureFragment` (`sd4/ol.java`) - host ekranu Ustawień aplikacji mObywatel. Przyjmuje opcjonalny deep link i punkt wejścia (Parcelable), po czym wybiera fabrykę nawigacji ekranu ustawień i renderuje go w Compose; po powrocie z ekranu wysyła zdarzenie nawigacyjne `TAG_SETTINGS`.

### Endpointy
brak (brak HTTP; deep link przez `NavHostController.F(Uri)`)
