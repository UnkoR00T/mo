# 197_model.md
### Rola
Fragment Compose `VehicleHistoryFeatureFragment` (`sd4/rn.java`) - host ekranu historii pojazdu. Odtwarza z argumentów komplet danych identyfikacyjnych pojazdu (numer nadwozia VIN, rejestracja, flaga pominięcia formularza, data pierwszej rejestracji) i renderuje ekran historii; obsługuje deep link oraz powrót do tagu `VehicleHistoryFragment`.

### Endpointy
brak (brak HTTP; deep link przez `DestinationNavigator.getNavController().F(Uri)`)

### Modele danych
`sd4.rn` -> VehicleHistoryFeatureFragment (ComposeView, `sd4/rn.java`)
- `fragmentNavigator` (`rh2.a`, `L0`): FragmentNavigator - powrot do tagu `VehicleHistoryFragment` (`f2()`)
- `deeplink` (`Uri`, `M0`): Uri - deep link do nawigacji (Bundle `"deepLinkUri"`, klucz metadanych `KEY_DEEP_LINK`)
- `vehicleIdentificationData` (`pj3.VehicleIdentificationPayload`, `N0`): dane identyfikacyjne pojazdu dla ekranu historii (pole prywatne, wypełniane w `x0`)
- `INSTANCE` (`O0`): Companion - fabryka; metadane: `VEHICLE_HISTORY_FRAGMENT`, `KEY_DEEP_LINK`, `KEY_VIN`, `KEY_PLATE`, `KEY_SKIP_FORM`, `KEY_FIRST_REGISTRATION_DATE`
- `pj3.VehicleIdentificationPayload` -> VehicleIdentificationPayload (payload ekranu historii pojazdu; `pj3/VehicleIdentificationPayload.java`): ctor 5 argumentow wg kolejnosci uzycia `new VehicleIdentificationPayload(plate, vin, skipForm, firstRegistrationDate, null)`, czyli:
  - param 1: wynik `uv0.d.c(plateString)` - zmapowana rejestracja pojazdu (typ `uv0.d`, brak pliku w `md/`)
  - param 2: wynik `uv0.v.d(vinString)` - zmapowany VIN (typ `uv0.v`, brak pliku w `md/`)
  - param 3: `boolean` - czy pominac formularz identyfikacji
  - param 4: `java.time.LocalDate` - data pierwszej rejestracji
  - param 5: `null` - parametr opcjonalny/wartosc domyslna (maska `f158028e << 9` wskazuje 5. argument jako domyslny; nazwy brak w kodzie, nie zgadywac)
- `dj3.a` / `dj3.d.f42907a` / `dj3.e.f42909a`: interfejs hosta zawartosci ekranu historii pojazdu + dwa warianty wybierane przez `w0.h0.a(...)` (pierwszy = `dj3.d`, drugi = `dj3.e`)

`c2(rn)`: `fragmentNavigator.c("VehicleHistoryFragment")` - powrot na ekran historii pojazdu (`sd4/rn.java:129`).

`b2(...)`: przekazanie do `ej3.d1.I(aVar, onNavGraphReady, onFinish, rn.vehicleIdentificationData, ...)` (`sd4/rn.java:118`).
`Companion.a(Uri, String vin, String plate, Boolean skipForm, LocalDate firstRegistrationDate)`: Bundle z kluczami `deepLinkUri`, `VIN_VEHICLE_HISTORY`, `PLATE_VEHICLE_HISTORY`, `SKIP_FORM_VEHICLE_HISTORY`, `KEY_FIRST_REGISTRATION_DATE` (data zapisana jako `firstRegistrationDate.toEpochDay()` - dzien epoki) - kazdy tylko gdy nie null (`sd4/rn.java:51-71`).
