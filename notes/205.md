# 205_model.md

### Rola
`ti/b.java` to wewnętrzna klasa pomocnicza biblioteki **Material Components for Android** (`com.google.android.material`) — parser atrybutów XML i holder odczytanych wartości dla odznaki Material (`BadgeDrawable`). Klasa `ti/b$a` (Parcelable.Builder) przenosi wartości między instancjami/widokami; brak logiki aplikacji mObywatel i brak danych sieciowych.

### Endpointy
brak — brak HTTP/Retrofit, brak URL, brak auth i podpisywania. Jedynie odczyt zasobów: `Context.getResources()`, `TypedArray`, `context.getString(...)`.

### Logika
- Konstruktor `ti/b(Context, styleRes, defStyleAttr, defStyleRes, a)` (`ti/b.java:68-142`) — jeśli podano `styleRes != 0`, jest on przepisywany do buildera; `TypedArray` powstaje w `a(...)` przez `n.i(context, attrs, l.g, defStyleAttr, styleAttr, new int[0])`. Każde pole `b` (kopia) dostaje wartość z `a`, a gdy `a` ma `null`/`-2`, fallback z `TypedArray` lub z zasobów.
- Sentinel `-2` oznacza „nieustalone": `j` → maska, `l` → `-1` gdy brak atrybutu, `m`/`n` → `getInt(..., -2)`.
- `showBadge`: `w == FALSE` wymusza `z15 = false`, w przeciwnym razie true (`ti/b.java:105-108`).
- Kolory: gdy brak jawnych atrybutów, kolor bazy bierze się z palety `new ij.d(context, baseColorResId).j().getDefaultColor()` (`ti/b.java:122`), a pomocnicza `G(context, typedArray, attr)` to `ij.c.a(...).getDefaultColor()`.
- Odstępy `B` i `C` dziedziczą wartości `z` i `A` jako domyślne wymiary (`ti/b.java:129-130`).
- Locale: `Locale.getDefault(Locale.Category.FORMAT)` gdy brak jawnie podanego (`ti/b.java:136-140`).
- Gettery `b()`–`y()` oraz `A()`–`F()` to czyste akcesory do pól klasy `f190387b`; `C()` = `l != -1` (czy widoczność ustawiona), `D()` = `k != null` (czy kotwica), `F()` = showBadge, `E()` deprecated = `G`.
- `H(int)` nadpisuje kolor/maskę w obu obiektach (źródłowym i docelowym) — `ti/b.java:186-189`.
- `TypedArray.recycle()` po odczycie (`ti/b.java:135`). Brak agregacji, interwałów, operacji na danych domenowych.

### UI / metryki
Wyłącznie warstwa UI biblioteki Material: odznaka (`Badge`) nakładana na `app:badge`, `app:badgeText`, `app:badgeBackgroundColor`, `app:badgeTextColor`, `app:badgeColor` (paleta), `app:maxCharacterCount`, `app:showBadge`, `app:badgeHorizontalOffset`/`badgeVerticalOffset`, `anchorViewId`. Metryki aplikacji brak. Wartości stałe z kodu: maska koloru `0x1F`, domyślny kolor tła `8388661`, domyślne warianty `ri.i.a` / `ri.j.o`.

### Brakujące klasy
- `ri/d` — indeks zasobów/wymiary Material (`d.S`, `d.U`, `d.o`, `d.p`, `d.T`, `d.q`).
- `ri/l` — indeks atrybutów `TypedArray` Material (`l.g`, `l.j`, `l.m`, `l.w`, `l.u`, `l.z`, `l.v`, `l.D`, `l.E`, `l.F`, `l.i`, `l.n`, `l.o`, `l.x`, `l.y`, `l.q`, `l.r`, `l.k`, `l.t`, `l.s`, `l.A`, `l.H`, `l.B`, `l.C`, `l.I`, `l.p`).
- `ri/i`, `ri/j`, `ri/k` — stałe stylów/wariantów/domyślnych id Material.
- `ij/c`, `ij/d` — resolver kolorów Material (`getDefaultColor`, paleta).
- `com.google.android.material.internal.n` — `n.i(...)` tworzenie/obróbka TypedArray, oraz `com.google.android.material.drawable.c.i(...)` wczytywanie `AttributeSet` z zasobu.
- `org.bouncycastle.pqc.crypto.rainbow.GF2Field` — użyta wyłącznie jako źródło stałej maski `MASK` (artefakt deobfuskacji jadx).
