### Rola

Klasa zamienia surową wartość JSON (`iy.b0`) na tekst gotowy do pokazania w UI, korzystając z typu pola (`gv1.s`), referencji pola, słownika tłumaczeń enum/boolean oraz z mappera etykiet na zasoby zdalne. ### Logika
- **Formatowanie wg typu pola** — `c(...)` (`tv1/d.java:178-226`), zawsze `jsonFieldParser.b(fieldReference, c0.e(jsonValue))`:
  - `NAME` (1): jeśli `fieldsReference != null` — konkatenacja wartości wszystkich pól rozdzielona spacją (`sb.append(strB + ' ')`); w przeciwnym razie jedno pole. Trailing spacja zostaje.
  - `DATE` (2): parsowanie `fz.b.String(value, fz.c.DASHED_REVERSED)` → formatowanie `fz.c.DOTTED`; `null` gdy brak wartości.
  - `DATE_TIME` (3): `fz.c.OFFSET_DATE_TIME_SEC` → `fz.c.DOTTED_TIME_PLUS_DATE`; `null` gdy brak wartości.
  - `ENUM` (4): `m(..., enumTranslations ?: emptyList())` — pierwsze tłumaczenie, którego `getEnumValue()` jest równe wartości pola (porównanie `t.c`), zwraca `a(...)` (przez mapper etykiet). Brak dopasowania → `throw NoSuchElementException("Collection contains no element matching the predicate.")` (`tv1/d.java:130-137`).
  - `BOOLEAN` (5): `l(...)` — `true` → `a(translation.b())`, `false` → `a(translation.a())`; przy pustej liście tłumaczeń zwracane `null`; brane wyłącznie `booleanTranslations.get(0)` (pierwszy element) (`tv1/d.java:122-128`).
  - `MULTILINE_TEXT` (6): `jsonFieldParser.c(...)` → lista wartości sklejona `"\n"` (`v.v0(..., "\n", ...)`); `null` gdy brak.
  - `UNKNOWN` (7): zawsze `null`.
  - `default`: surowa wartość pola z `jsonFieldParser`.
  - Brak wartości w ENUM/BOOLEAN zastępowane pustym stringiem (`str != null ? str : ""`).
- **Filtr dostępnych atrybutów** — `b(List<DocumentSchemaAttribute>, b0 data)` (`tv1/d.java:148-175`): wyniki w `LinkedHashSet` (deduplikacja + zachowanie kolejności). Dla atrybutu z `fieldReference != null` → `i(fieldReference, ...)`. Dla atrybutu z listą referencji (`e() != null`) → iteracja po wszystkich referencjach, każda sprawdzana niezależnie; jedno trafienie wystarcza. `i()` woła `d(reference, data)`; brak trafienia → atrybut dodawany **tylko** gdy `onMissingAttribute != null && getOnMissing() == MissingDocumentAttribute.a.DEFAULT_VALUE`, wtedy `filterCallback.a()` (`d.j`/`d.k` → `set.add(attr); return i0.f148189a`). Wynik: `v.f1(linkedHashSet)` (lista).
- **`i(...)`** — przed sprawdzeniem referencja jest przepuszczana przez `r.V0(fieldReference, new String[]{"."}, false, 0, 6, null)`, czyli sprowadzana do klucza najwyższego poziomu (widoczne z `d()`), po czym porównywana z kluczami dokumentu (`tv1/d.java:99-108`).
- **`d(fieldReference, data)` — istnienie pola** (`tv1/d.java:229-247`): `data` → tekst JSON (`c0.e`) → `new JSONObject(...)`; iteracja po kluczach najwyższego poziomu, dla każdego `getJSONObject(key)` iteracja po jego kluczach i porównanie `t.c(next, fieldReference)`; `true` przy pierwszym dopasowaniu, `false` gdy żaden klucz nie pasuje. Zakłada, że dokument ma kształt `{ obiekt: { pola } }` (dwa poziomy zagłębienia).
- **PESEL** — `e(documentPeselFieldReference, jsonValue)` (`tv1/d.java:250-256`): deleguje do statycznego `ev1.a.f(this, s.TEXT, documentPeselFieldReference, null, null, jsonValue, null, 44, null)`, a wynik tekstowy zawija z powrotem przez `c0.g(...)` w `b0`; `null` gdy `null`.
- **Etykiety** — `a(List<DocumentSchemaLabel>)`: `null` → `null`, inaczej `documentRemoteResourcesMapper.a(label)`.
- Brak interwałów, agregacji liczbowych, cache, retry.
