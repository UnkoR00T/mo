# 236_model.md

### Rola
Aplikacyjny **model danych karty pełnomocnika / posła** (`DeputyCardData`, Kotlin `data class`, `Parcelable`) — pierwsza klasa z paczki 232-243 należąca do logiki domenowej mObywatel, a nie biblioteki. Przechowuje dane osoby posiadającej kartę: imiona, numer karty, numer kadencji Sejmu oraz datę wydania. Nazwy pól w JSON-ie ukryte są pod skrótami (`n`, `s`, `su`, `no`, `pTNo`, `rD`) nadanymi w adnotacji serializującej `@vl.c`.

### Endpointy
brak — klasa nie zawiera żadnych wywołań sieciowych, URL-i, parametrów ani podpisywania. Jest wyłącznie nośnikiem danych (pobieranych w innej paczce, prawdopodobnie z API Sejmu/Prezydium).

- `createFromParcel`: odwrotność `writeToParcel` — 6× `readString()` w tej samej kolejności (plik: `yh2/DeputyCardData.java`)
- `toString()`: `"DeputyCardData(firstName=..., secondName=..., lastName=..., number=..., numberOfSeymCadency=..., releaseDate=...)"` (plik: `yh2/DeputyCardData.java`)

### UI / metryki
brak w tej klasie — brak ekranów, kafelków i wartości formatowanych.
