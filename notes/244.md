# 244_ui.md

### Rola
Interfejs Retrofit (grupa `companyservice_release`) dla słowników firmowych w module „Działalność gospodarcza / firma": kody PKD, dostawcy poza ewidencją (dostawa elektroniczna), fundusze KRUS i urzędy skarbowe. To warstwa sieciowa dla ekranów firmowych (lista dokumentów/kafelki PKD na PULPIT-cie firmowym), nie komponent UI.

### Endpointy
Wszystkie w `ak0/e.java`, adnotacja `@f(...)` (Retrofit), brak jawnej metody HTTP (domyślnie Retrofit `GET`) i brak jawnego `@Header`/`Authorization` (dodawane przez interceptor aplikacji).
- `company/mobile/api/dictionaries/pkd` -> `x<CompanyActivityCategoriesDto>` (słownik kategorii działalności PKD)
- `company/mobile/api/dictionaries/non-public-supplier` -> `x<ElectronicDeliveryNonPublicSuppliersDto>` (dostawcy spoza ewidencji / dostawa elektroniczna)
- `company/mobile/api/dictionaries/krus` -> `x<SocialInsuranceFundsDto>` (fundusze ubezpieczeń społecznych KRUS)
- `company/mobile/api/dictionaries/us` -> `x<TaxOfficesDto>` (urzędy skarbowe)

### Modele danych
Klasy DTO `ck0/*` (pakiety 277-281_ui.md: `CompanyActivityCategoriesDto`, `ElectronicDeliveryNonPublicSuppliersDto`, `SocialInsuranceFundsDto`, `TaxOfficesDto`) – w tym pakiecie tylko nazwy typów zwracanych, bez pól. Wspólny wrapper odpowiedzi: `ge4.x` (pakiet 285_ui.md).
Typy pomocnicze z `@Metadata`: `tq.e` = parametr callback/suspending wrapper (Kotlin suspend), `ck0.b1/c/n1/p1` – klasy pomocnicze odpowiedzi (w tym pakiecie brak definicji).

### Logika
Brak logiki obliczeniowej – to deklaracje metod. Każda metoda przyjmuje parametr typu `tq.e<? super x<...>>` (wynik opakowany w `ge4.x`), czyli każde wywołanie zwraca opakowany rezultat (błąd/sukces) do warstwy wyżej. Brak filtrów, agregacji, interwałów odświeżania.

### UI / metryki
Brak komponentów UI w tym pakiecie – zero layoutów, kompozycji, stringów zasobów, metryk. Zastosowanie pośrednie: cztery słowniki (`pkd`, `non-public-supplier`, `krus`, `us`) zasilają formularze/filtry dokumentów firmowych (PKD = kafelki/kategorie działalności, KRUS/US = wybór płatnika i płatnika ZUS/US przy złożeniu wniosku).

### Brakujące klasy
`ck0/CompanyActivityCategoriesDto`, `ck0/ElectronicDeliveryNonPublicSuppliersDto`, `ck0/SocialInsuranceFundsDto`, `ck0/TaxOfficesDto`, `ge4/x` – brak definicji w tym pakiecie (definicje w 277-281_ui.md i 285_ui.md).
